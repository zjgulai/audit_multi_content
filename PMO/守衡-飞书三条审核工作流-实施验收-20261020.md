# 守衡飞书三条审核工作流：实施与验收记录（2026-10-20）

## 目标与边界

依据当前上游《内容审查 Agent PRD》v1.4，完成飞书问答及文本、图片、链接三类终稿送审工作流的 specification、ticket 拆解、代码/技能契约对齐和离线验收。本轮不包含视频、文件、批量/NAS、审批投递、签字确认及知识库反馈。用户已授权在专用测试群发送四条验收输入；在线验收已完成，另对流程问答作了确定性答复修复和复验。知识库留底入库仍待具备 `kb_ingest` 的环境补录。

本地 PRD 副本和索引仍是旧基线。上游 PRD 于 2026-10-20 只读拉取，`verify_prd_baseline.py` 发现本地指纹/字符数/最后修改时间及 H3 引用映射存在漂移。本轮按新版本制定规格，但没有改写基线文件或上游 PRD。

## 工作流判断

审计确认技能文档本身不会在守衡运行时自动加载；真正路由由 `tools/agent/review_gate.mjs` 控制，`agent.mjs` 负责材料与送审链协调，`ws_daemon.mjs` 承担飞书收发。因此优化重点是把技能写成流程地图，并让自证器对照代码锚点；行为正确性由离线运行测试证明，不能以文档存在替代。

初审发现链接路由只保留 URL 字符串、未读取网页正文，技能/规格却写成已有工具会读取页面。这一差距已补为受限公网读取器，正文送入原审核链；失败时固定非 PASS 回复且跳过审核链和业务写入。机制问答、文本、图片及正文+URL 路由保持原行为。

## 在线问答修复与最终复验（2026-10-21）
