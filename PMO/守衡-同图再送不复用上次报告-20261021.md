## 一、起因：判定本来就重跑，**产物**没有

先把两件事分开（问「会不会参考第一次的结果」时必须分开，否则怎么答都错）：

| | 结论 |
|---|---|
| **判定** | **每次重跑，没有跨次复用。** 旁挂 `kb/.work/last_review_result.json` 取用前要过身份闸 + 时间闸（令牌 / 文本指纹 / 内容 ID 任一不符、或 `at` 早于本单起点 ⇒ 拒收、按「库侧没读数」走，`tools.mjs` 的 `readReviewSidecar`）；同一轮内重复调工具才回缓存 |
| **产物** | **有一处在复用** —— 见下 |

实测读数（可复现：`node test/_lat/repeat_review_probe.mjs`）：

```
机读台账 347 单 ｜ 素材键 191 个 ｜ 被重复送审 ≥2 次：68 个
其中结论**变过**的：22 个（结论一致 46 个）   ← 结论会变，说明判定确实每次都重跑
结论表 272 行 ｜ AUTO- 内容指纹 124 行 ｜ 链侧 AD- 当日序号 148 行
```

**病灶**（`tools/agent/tools.mjs` 的 `p0HitPayload`）：`prevReport ? 用旧的 : (allowPublish ? 建新的 : 留空)`
—— 只要同一内容以前出过报告，这一单就**永远不建新的**。于是同一张图第二次送审时：

- `Agent 结论` 按本单重判（`CONCLUSION_DERIVED_FIELDS` 允许改写）；
- 而「报告链接」这一格指向**第一次**那份 ⇒ **人点开读到的是上一次的结论与时间戳**。

这条行为当初（2026-10-06 方案 c）是为了防「新报告成孤儿」，而它写成内联 if/else 的那些天里，
**没有任何一条断言能走进去**（§2.4：判据没盖住的那一跳，就是事故所在的那一跳）。

## 三、判据在哪、自证怎么跑

```
node tools/agent/p0_report.test.mjs      # 16 / 16 —— 本次新增
node tools/agent/review_publish.test.mjs # 44 / 44
node tools/verify_cards.mjs              # 349 项通过 / 0 不通过
```

新自证分三层（与 §2.4 那条教训对齐：**「名字出现过」不是「它拦得住」**）：

- **A 组 判据**（纯函数 8 条）：「送审 + 本单出成 ⇒ 用本单的」「没出成 + 有旧 ⇒ 回落且 detail 必须写清」
  「没 report_path ⇒ 不许拿旧的顶上」「只读前置 ⇒ 边界未变」…
- **B 组 接线**（真调 `p0HitPayload`，三跳全打桩）：**建文档这一步被调了几次**。旧代码在
  「以前出过报告」时这里是 **0 次**，B1 就是冲它去的；B2 反向对照：只读前置**一次都不许调**。
- **C 组 反向对照**：喂一段含旧分支指纹串的坏样本 ⇒ 扫描器必须红（否则 C1 恒真）。

**变异自证**（每个变异都当场跑，确认会红，再还原）：

| 变异 | 结果 |
|---|---|
| `p0ReportOutcome` 开头加 `if (prev) return 旧的`（= 回到改之前） | **16 项里 10 项红**（A1/A2/A3/A4/A6/A7 + B1/B3/B5/B6） |
| `publishDoc` 调用条件加 `&& !prevReport`（= 只有没旧报告时才建） | **B1 红**，其余 15 绿 |

## 四、没做完 / 没验到的（不许当成已验）

1. **没有重启守衡**（`AGENTS.md` §2.7：重启要先问）。这两处都在 `ws_daemon.mjs` 的 import 图里
   ⇒ **改动此刻还没生效**，下次重启才生效。
2. **一次「红」是别人的半成品，不是本次的**：第一次跑 `node tools/test_agent.mjs` 时读到
   `通过 296 / 失败 3`（`Z17 ★ 接线：报告经注入发布…` 两处同名断言 ＋
   `Z48b ★★ 反向对照：图片 skill 未完整执行时不发布合格报告`）。
   那三条读的是 `agent.mjs` / `merged_report.mjs` 的源码与 `shouldPublishMergedReport`，
   **本次一个字都没动那两个文件**；而运行期间它们的 mtime 在变
   （`merged_report.mjs` 16:35、`agent.mjs` 16:38、`test_agent.mjs` 16:39）
   ⇒ **另有一条线正在改图片审查那一段，我读到的是半成品**。
   ⚠️ 这正是「跑一次自证 ≠ 那一刻的盘是本单的盘」：判据读的是**源码文本**，源码在动，读数就不稳。
   等它收口（16:39 后不再变）重跑：**通过 299 / 失败 0，rc=0**，才是本单该记的读数。
   （第一次那个 `296/3` 不作为本单结论，留在这里是为了记下「跨会话并发」这个形状。）
3. 台账里 `AD-日期-序号` 会被链侧写成**同一个号挂在多行**（实测 `AD-20261020-001` 6 行，
   其中一行是纯文字单）⇒ 表里「内容 ID」这一格**不能当素材身份读**。本次没动它（那是链侧的号），
   但谁要拿它做去重，先看这条。
