# DSH 活动库规则缺口与快照行级差异

日期：2026-10-22  
依据：当前 PRD §5.2、§7.2；活动库与仓库快照现场读取。  
机器明细：[完整 JSON 缺口/行级差异报告](DSH规则缺口清单-活动库快照对比-20261022.json)

## 结论

- L3 规则 1,020 行、外部标准 129 行，合并后 639 个唯一 `rule_id`；其中 P0 63 个。
- 639/639 个唯一规则 ID 均缺至少一个 PRD §6.5 元数据字段；63/63 个 P0 规则也在缺口清单中。字段缺项彼此重叠，不能相加成受影响规则数。
- `applicable_scope.content_type` 在 639 条里全部没有显式值。旧 `modality` 字段有 516 条为 `text`、123 条缺失；它不等价于 PRD 的适用内容类型，不能据此补值。
- PRD §7.2 九个场景均标记 **UNMEASURED**：当前没有经批准的规则分类到场景映射，也没有应审规则/黄金样本分母。场景名相似不作为覆盖证据。
- P0 规则码集合 L3/L5 为 19/19 一致；这验证代码集合一致，不代表模式内容、规则适用面或语义覆盖已充分。

## 当前限制与后续动作

1. 规则内容类型、渠道、产品线、风险等级、来源锚点、版本和负责人字段值需要从权威源逐条确认；本报告不生成建议值。
2. 先处理 63 个 P0 ID 的来源与适用范围确认，再按已批准的映射建立九场景覆盖分母和黄金回归集。
3. 确认权威端后才生成 L3/L5；审阅模式扩缩差异并跑 P0 matcher、fastpath 与跨模态回归。
4. 本报告只读活动库和仓库快照。写入的 JSON 是独立证据文件，不是活动知识库规则数据。
