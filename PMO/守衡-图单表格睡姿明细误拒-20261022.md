# 守衡图单睡姿核对表格明细误拒修复（2026-10-22）

## 现象

## 根因与为何反复修

前几轮修复分别补了方位别名（右上→顶部）和显式面板别名（面板 A/B→右上/右下），但测试都把面板姿势放在单行或固定的别名形式中。实际模型可把视觉核对拆成 Markdown 表格：睡姿类别/结论在父行，面板 A/B 的读数在其后连续表格行。`sleepPositionEvidence()` 原先只采父行或缩进列表，遇到下一张表格行即停止，于是已有的逐面板证据未进入睡姿匹配，误报为遗漏。

重复修复的原因是**按单次报告措辞补别名，没有覆盖同一语义的另一种结构化输出形式**；判据的输入范围与生产输出形状不一致。不能通过放松逐面板要求解决，缺任一面板仍须拒绝。

## 修复

- `tools/agent/visual_checklist.mjs`：睡姿类别位于 Markdown 表格时，聚合后续连续明细行；遇到下一个视觉类别即停止，避免跨类别借证。
- `tools/agent/scene.test.mjs`：新增 S5j，覆盖父行 + 面板 A/B 表格明细；正向确认两面板通过，反向删除右下面板后仍拒绝。
- 仅影响视觉清单证据归集，不改变姿势判定、知识库结论或三态规则。
