## 一、缺口到底在哪（逐行核过，不是推测）

`build_view.py` 报告里的 `ok` **只比派生那一半**：

```python
rep["ok"] = (not rep["missing_entries"] and not rep["installed_enveloped"]
             and (rep["loader"].get("E001") or 0) == 0
             and (rep["loader"].get("E046") or 0) == 0
             and rep["loader"].get("entries") == rep["expected_entries"])
```

⇒ **`ok=True` 一个字都没说外来条目。** 而它删文件那一跳长这样：

```python
rep["stale_removed"] = sorted(r for r in _old_derived - _new_rels
                              if os.path.isfile(os.path.join(OUT, r)))
for _rel in rep["stale_removed"]:
    os.remove(os.path.join(OUT, _rel))
rep["preserved_foreign"] = sorted(...)   # ← 事后把盘上**剩下**的记一笔，不是断言
```

判据是「**上一轮是派生的、这一轮不是了**」⇒ 删。`preserved_foreign` 是**事后统计**，
不是「该留的都留住了」的证明。**所以那句散文当时真的没人守。**

## 三、判据：`kb/l8/check_view_foreign_survival.py`

**只读，不跑重建** —— 这一条是给「不许影响工作流」配的：

> `build_view.py` **没有非破坏模式**（`--out` 默认就是线上视图 `kb/view`）。
> 为了核一条「重建后还在不在」而**真去重建一次线上视图**，代价与风险都远大于这条读数：
> 重建会重写整个 `kb/view/`，而它正被别人用着（`kb_guide` / `kb_search` / 就绪巡检）。
> 构建报告是 `build_view.py` 自己落的 `kb/l8/view_build_<run>.json`，盘上的条目就在 `kb/view/` 里 ——
> **两样都不需要动。**

判据两半 ＋ 一条可见性：

- **F1** 当下盘上的外来条目 **⊇** 最近一次构建报告里的 `foreign_entry_md`（报告认过的，一条都不许少）；
- **F2** 相邻两次报告之间**只增不减**（外来条目是人工入库的，少一条就是「重建删了」）；
- **F3** **看得见** —— 逐条列出来，不是只报一个数；
- **未测**：一份构建报告都没有 ⇒ F1/F2 无从谈起，记**未测**、不判红。

### 3.1 它第一次真跑就吐了一条**假红**（值得单独记）

按 run 名排序 ⇒ `CHK-20261004-0152`（**10-04**）被排到了 `20261010-1233`（**10-10**）**后面**
（ASCII 里数字 < 字母）⇒ F2 报「后一轮少了一条」，而少的正是 10-05 才入库的
`ref-content-review-kb-plan-v2-5` —— **一条纯粹的假红**。

修法：排序键改取报告自己的 `at`；没有 `at` 的排最后（宁可少比一对，不许比错一对）。
**这一半已钉进反向对照**（`--selftest` 的第 ⑤ 半）—— 少了它，另外四半全绿也照样在真库上吐假红。

> 本仓原话：**一条假红会挤掉一个真问题。**

### 3.2 反向对照 `--selftest`（**五半**）

| 半 | 喂什么 | 必须 |
|---|---|---|
| ① | 正常（盘上 ⊇ 报告、报告只增） | **不报红** |

## 四、接线：**非阻断**（这就是「不影响工作流」的落点）

挂进 `ci/run_gates.py` 的 `view_foreign`（`blocking=False`）。

**为什么必须是非阻断、且必须只退 0/3**：`run_gates.py` 对非阻断闸门**分档** ——

```python
if not blocking:
    if rc == 3:
        rec["state"] = "WARN"          # 不改 runner 退出码
    elif rc in (1, 2):
        rec["state"] = "ERROR"         # ⇒ 会把 runner 打到退出码 3
```

⇒ 本脚本**只退 0 或 3**（异常也自己兜成 3），**绝不用 1/2** ——
免得一条本意是「读数」的东西把 CI 变红。
