# 报告第二十三轮：链接只来自两处（作者：Owner 一句话问出来的缺陷）

> Owner 原话，逐字：
> 「**你送的文案，为什么给　“链接：点开”　这链接跳转是哪里？**」

---

## 一、直接回答

那一行不是素材链接，**是我从文案正文里挖出来的一个 URL**，而且它指向的域名**不是我们的**。

| 项 | 值 |
|---|---|
| 报告里那一行 | `> **链接**：[点开](http://production.it/)` |
| 那个 URL 从哪来 | **素材正文自己带的**：`…effectively increasing milk [production.It](http://production.it/) supports everyday baby essentials needs.` |
| 它为什么长成链接 | 原文是 `increasing milk production.It supports`，`production.It` 后面紧跟句号 —— **粘贴时被编辑器自动做成了 markdown 链接**（把 `.It` 当成域名后缀 `.it`） |
| 域名归属 | `production.it` 是**.it（意大利）下的一个公开域名**，与 Momcozy、与这条素材**没有任何关系**（实测 `http://production.it/` 返回 200，是一台活着的站点） |
| 谁把它印上去的 | **我**。第二十二轮我加的规则是「裸 URL 在文案里出现时单列一格」，于是把这段正文里的 URL 挖出来单独印成了「链接：点开」 |

**最难看的一点**：同一份报告的第 5 条问题，问题描述原文就是
「『milk production』后面直接粘着一个 markdown 链接残留『[production.It](http://production.it/)』…」——
**一边把它判成缺陷，一边给它做了一个可点入口**。Owner 就是被这一行问住的。

---

## 二、改了什么（两条硬规矩）

### ⓐ 链接只来自两处，**绝不从正文里挖**

1. **我们上传的媒材**（`media_link.collectMediaLinks()` → 飞书云空间、设「组织内可阅读」并回读确认）；
2. **这一单本身就是链接送审**（`gate.kind === 'link'`）—— 此时 URL 才是**送审对象**，
   由调用方**显式**传 `links` 进报告。只认 `http(s)`；`javascript:` / `ftp:` 之类一律忽略。

普通文案里粘着的 URL **一个都不挖**（第二十二轮那条「裸 URL 单列一格」**作废**）。

### ⓑ 引用原文 ≠ 替原文做入口

- 文案里的 markdown 链接语法**降成纯文字**：`[production.It](http://production.it/)` → `production.It`；
- 引用里出现的裸 URL 一律包成**行内代码**（`` `https://…` ``）—— 飞书会把裸 URL 自动变超链接，
  包成代码就不会，且读者一眼看出「这是原文里的字」；
- 这一条**覆盖除「依据文档链接」之外的所有格子**：维度 / 位置 / 问题描述 / 原因 / 修改建议，
  以及「一、问题总览」表的每一格。

**为什么验收时又改了一版**：先把「审查对象」那一行改完（rev 13），回读发现**文档里仍有一个
指向 `production.it` 的超链接** —— 来源是**第 5 条的问题描述**逐字引用了那段 markdown。
⇒ 清扫必须覆盖**所有引用原文的格子**，不能只改审查对象。

「依据文档链接」那一格**保持可点**：它是**我们自己的**飞书直链（回源用），
以及模型侧引用的**公开依据**（实测这份报告里有 FTC《Health Products Compliance Guidance》
与 Amazon Ads 的《Claims and substantiation》）—— 那是证据，能点开是优点。

## 三、判据

新增 `Z49e`（拆掉修法就精确变红）：

| 判据 | 盯什么 |
|---|---|
| 文案里的 `[x](http://…)` | **不许保留链接标记**，文字要留下（`production.It supports`） |
| 非链接送审的正文里有 URL | **不许出现「链接」那一行** |
| 文案里的裸 URL | 必须包成行内代码（否则飞书自动变超链接） |
| **反向对照**：真·链接送审 | **必须**给 `[点开](url)`（否则上面那条只是「什么都不做」） |
| `links` 传了非 http(s) | 一律忽略，且**正文里的 URL 也不许被做成链接** |

## 五、边界

1. **这不是「素材里有链接」这一类问题的通用解**：如果对方**真的**发来一个落地页链接要审，
   那是链接送审（`kind === 'link'`），链接会正常出现在报告里（Z49e 的反向对照钉着这条）。
2. **外部依据链接仍然可点**：FTC / Amazon 这类是证据来源，不是陌生域名；要收掉它们得另定口径。
3. 第二十二轮那份留底件里「裸 URL 单列一格」那一句**已作废**，但**原文件没改**
   （改了会让已入库条目的 `source.fingerprint` 全部对不上）；作废声明写在这里，
   知识库侧的订正走「新建 + `supersedes`」。
