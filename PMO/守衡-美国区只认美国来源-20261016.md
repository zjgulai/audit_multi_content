## 三、缺口：菜单挡住了，**解析没挡**（本次修的）

实测（修前）：`basisText({ source: 'S15' })` **照样把 MHRA 的英国链接挂上去**并标成
「登记来源」；`S16` 同理。也就是**能递到它面前的**（15 条）与**能被挂上报告的**（17 条）
**不是同一个集合** —— 只关了半扇门。模型在菜单里看不到 S15/S16，但它**猜中一个 id**（或哪天
菜单又被改宽）就会有一条域外依据进对外报告，而**没有任何断言盖住它**：
自证当时只覆盖了无效 id（`S99`／小写／空／null／注入串）。

**修法**：口径统一成 `辖区 === 'US'`，非美国 id 与未知 id **同样 fail-closed**；
但**两支不许混成一支** —— 未知 id 是「没给来源」，非美国 id 是「给了、按美国口径不作数」，
后者要**照实写出来**（点了哪个 id、辖区是什么、为什么不给链接）并**落台账**
（`PMO/logs/nonus-cite.ndjson`，可数）。**丢弃不留痕＝静默消失**，那正是本项目反复吃过的形状。

★ 实现上把解析抽成**纯函数 `basisTextOf(sources, f)`** 并显式接收来源表 ——
否则「挡住它的到底是不是辖区」这条反向对照只能靠读源码去证。

## 四、判据（`node tools/agent/ext_basis.mjs --selftest`，**32/32**，新增 7 条）

- S15／S16 ⇒ **不给链接**，且 `kind=non-us`（与未知 id 那支**能分辨**）；
- 报告行要**照实写出来**（含 id、辖区、「不作判据」）；
- **留痕**：两次被拒 ⇒ 台账 **+2**（自证把 `SHOUHENG_NONUS_CITE_LOG` 指到 `/tmp`，
  真台账一个字节不写 —— §2.4.4，跑完核过 `PMO/logs/nonus-cite.ndjson` **不存在**）；
- **反向对照①**：把 S15 的辖区改成 `US` ⇒ **又挂得上链接**（证明挡住它的是辖区，不是别的）；
- **反向对照②**：未知 id（S99）仍走原来那一支，且**不落**台账。

**看得见的那一半**（`ws_daemon.mjs` 心跳 ＋ `verify_shouheng_ops.py` J4/J5，共 **85** 项断言）：
心跳里多一条「⚠ 域外依据被挡 +N（累计 M）」；J4 读那本账（0 行 ⇒ 说「上线以来 0 次被挡」，
是事实不是未测），J5 是**接线断言**（只定义不调用 ＝ 写了没人看）。
★ J5 **做过反向对照**：把心跳里那行摘掉 ⇒ J5 变红；还原 ⇒ 又绿。
★ J5 第一版**假红**过一次 —— 我要求「心跳窗口里出现 `nonUsCiteCount()`」，
而那个调用在**心跳之前**的函数体里，心跳里调的只是 `nonUsCiteLine()`。
**一个写错的判据会报出一条指向无关方向的假红**，与「误报比不报更糟」同一条。
