# 「依据为外部标准」到底是怎么来的（2026-10-16 查证）

> 缘起：Owner 追问「你是跑的美国市场吗？依据的是哪个链接？跑了美国哪些网站？
> 不要写模型侧观察字样，检查为什么每次跑的结果都不一样」。
> 这份文件逐条把答案钉在代码与登记表上。相关：`PMO/守衡-调用方式不是素材-20261016.md`。

---

## 一、没有任何「跑美国网站」这回事

全仓只有三处联网（`grep` 可核）：模型端点（`llm.mjs`）、本机知识库 API
（`kb_client.mjs` → `127.0.0.1:4401`）、以及 `ext_basis.mjs` 对**已登记外部标准 URL**
做的存活探测（HEAD/GET）。**没有网页检索、没有抓取美国站点。**

## 二、「依据为外部标准」的真实机制（三跳，都有代码）

1. **模型侧是 LLM，不联网** —— 只读我们给的读数（OCR / 画面读数 / 转写）；
2. 它**只能从 17 个已登记来源里点一个 id**（`research/kb/外部标准库-v1.json`：
   **17 个来源 / 62 条条款** —— Amazon Ads ×6、Meta ×2、Google Ads ×2、FDA ×3、FTC ×1、
   TikTok ×1、MHRA ×1、ASA/CAP ×1；其中 **13 个是美国平台/监管机构**）。
   提示词里只给 **id + 机构 + 文档名，不给 URL**（`ext_basis.mjs` 纪律①：模型不许写 URL，
   幻觉链接比空格更坏）；
3. 代码把 id 换成**链接**，并用 **`pickWhere()` 的关键词重叠（≥3 词）**从该来源的条款里
   挑一条「条款位置」印上去（`basisText()`）。

## 三、于是「依据」有两种成色，报告必须分开写

| 成色 | 含义 | 例子（李倩怡那条图单） |
|---|---|---|
| **登记来源** | 模型点名了 S 库里的某个来源 → 挂出**真实存在的登记条款**（条款号 + 条款位置 + 变更指纹），但**条款位置是关键词匹配挑的，可能不对题** | 挂出 `EXT-034 / S12-01`：条款原文「Breast pumps are medical devices regulated by the FDA.」——**讲监管属性，不是清洁方式** ⇒ 与「冲洗带电部件危险」这条结论**不对题** |
| **无可引来源** | 模型没点任何来源、也没给出 URL ⇒ 报告只能写「无可引来源」 | 婴幼儿出镜、物件误读、四角水印三条 |

两条补充事实（都从登记表逐条读出来的）：

- 登记表每条都带 **`未确认标记: 研究稿·未经法务确认`**（S12 的四条全是）；
- 挂链接**不等于**我们读过那页正文：L0 那份 FDA 登记件写着
  `sha256_state = unreachable`、`status_reason = 抓取未返回正文，无法指纹`（`http_bytes = 10`）。

## 四、为什么每次跑结果都不一样（机制，不是"玄学"）

| 环节 | 确定性 | 证据 |
|---|---|---|
| 库侧检索 | **确定** | 两次都是 0 条（库里没有覆盖这张图的条款） |
| 画面层（吃图模型） | 不确定 | 同图两次措辞不同 |
| 模型侧（判定） | **不确定** | 调用 `temperature = 0.2`（写死在 `llm.mjs:281`，`model_side` 没覆盖）；**而且它这次点不点来源也是随机的** —— 第一跑点了 S12，第二跑一条都没点 ⇒ 两次零重合 |

⇒ 压住它的唯一办法：**温度降到 0 ＋ 改成固定维度逐项必答**（产品用途 / 婴幼儿 / 水印 /
图上文字 / 宣称 / 清洁示范…，每维必须答「有 / 无 / 看不清」），而不是让它自由发挥。

- 第 2 条标题从「无库内依据」改成 **「无可引来源」**，依据行直书
  「库内没有覆盖该题材的条款；本条也没有做任何联网查证（本系统不抓取美国网站）；
  要定它需要人工按美国市场规则确认」。
- 两条的落款从「无库内依据的改法建议」改成「改法建议 —— 不是库规原文」
  （**不打「模型侧」「知识库侧」这类标签**：这与 `ext_basis.mjs` 里 2026-10-13 那条
  措辞红线同一条）。

**踩到的坑（记下来免得下次再撞）**：`block_replace` 会把目标块换成**新的 block id** ——
写完要用新 id 再操作，否则后续指令静默「无变化」（`degrade_code=1011`）。
另：内容里写 `&gt;` 会被二次转义成字面量 `&gt;`（读的人看到的是一串实体），
改用 `›` 之类不触发转义的字符最省事。
