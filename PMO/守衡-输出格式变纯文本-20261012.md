# 守衡输出格式变纯文本（2026-10-12）—— 定位与修复

**一句话**：评审单的回复在**模型没给出卡片块**时会以**纯文本**发出，而飞书纯文本不渲染 markdown
⇒ 群里看到 `**加粗**`、反引号与一堆 `|`。修法 = 信封层加兜底：有权威结论行而模型没给卡时，**代码自己建一张**。

`📋 PRD §5.3 结论行：…｜落点=n/a·-｜逐条块=无`；会话原文
`PMO/shouheng-state/sessions/dm_ou_af95e2a43871579692afbb25a529e77e.json` 里对应 assistant 消息**不含 `[[card:`**。

`落点=n/a·-` 的含义：`shaped.verdict53` 是 `'text-lead'`（**纯文本路径**），不是卡片。

## 二、根因（两级，缺一条都解释不了）

1. **触发**：19:31 那一轮的用户消息被注入了另一个会话 17:54 加的
   「【本条是 P0 红线确定性命中 —— 请按**短卡**作答】…篇幅上限：正文 ≤ 300 字」——
   模型照做，**顺手把卡片块丢了**。该指令 19:40 停用、19:52 重启生效。
2. **残留**：停用之后模型**照样不给卡**（19:58、20:21 仍无卡块）⇒「模型会不会给卡」是**概率**，
   而 §5.3 的结论行是**必须**落下的东西。代码里**没有任何东西**把「有结论行却没卡」当回事：
   纯文本路径只把结论行前置（`leadWithVerdict`），其余照发，日志写一行 `落点=n/a·-` 就算过去了。

**连带伤害**：19:53 那条 878 字被整条丢掉 —— 纯文本**没有折叠区**可放内部标识
（命中的是 P0 模式号 `p-08487282e2d400fe`，而 16:48 新加的 `internalLeak` 规则本是为指纹/sha 写的）。
**卡片有折叠区、纯文本没有** ⇒ 两条症状是同一个根。
