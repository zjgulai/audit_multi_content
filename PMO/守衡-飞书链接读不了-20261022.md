## 一、现象（逐字，生产）

守衡回（`PMO/logs/ws_outbound.jsonl` 逐字）：

```

```

`PMO/logs/ws_daemon.log` 对应两行：

```
[agent] 🧭 送审闸门：link —— 贴了链接（1 条）—— 要读的就在链接里｜起链

```

## 二、真因（三层，逐条可核）

1. **这条链接是什么**：`drive/v1/metas/batch_query`（只读元数据）核实 ——
   `doc_type=file`、`title=【FINAL】Momcozy Wellness 1 红人Brief_职场妈妈版.pptx`。
   即**云空间附件**（`/file/`），不是文档。
2. **为什么报「域名解析到非公网地址」**：守衡的链接工作流只有一条读法 ——
   `tools/agent/link_reader.mjs` 读**匿名公网页面**。飞书网页一律 302 到
   `accounts.feishu.cn`（登录页），而本机 DNS 把这个域名解析到私网地址 **`10.0.0.100`**
   ⇒ SSRF 守卫拦下 ⇒ 报出那句话。**报错指向的是跳转后的登录域名，不是用户贴的链接**。
3. **它不只是这一条**：按同一条路复现三种飞书链接，**全部**死在同一句上：

   | 样本 | 结果 |
   |---|---|
   | `https://momcozy-in.feishu.cn/docx/Ybg1dZtoaoG5GKxLfREcHAK2nfs` | ERR 域名解析到非公网地址 |
   | `https://momcozy-in.feishu.cn/base/Lk3Qb8y2QaVyZns6gprcVNE9nA0` | ERR 域名解析到非公网地址 |
   | `https://momcozy-in.feishu.cn/file/IWbobAGHAoDcycxRFWNcBYd1nY6` | ERR 域名解析到非公网地址 |

   ⇒ **任何飞书链接都读不了**；就算 DNS 修好也读不到 —— 登录墙在那儿，匿名抓取本来就没有正文。

## 三、修法（分流点只有一个）

| 改什么 | 落在哪 |
|---|---|
| 新增飞书链接分流与读取：`readLink()` 是**唯一**分流点；飞书域名按路径取**只读正文**（`/docx/`→`raw_content`、`/sheets/`→工作表值、`/base/`→记录、`/wiki/`→`get_node` 再按 `obj_type` 分派） | `tools/agent/feishu_link.mjs`（新） |
| 链接闸门默认 reader 换成分流器；失败话术**原样透传**（分形态：红线不取 / 飞书没接口 / 权限或不存在） | `tools/agent/review_gate.mjs` |
| 两处默认 `linkReader` 同步改成 `reviewGate.readLink` | `tools/agent/agent.mjs`（`handleMessage` 与 `runSubmissionGate`） |
| 人设里的「工作流事实」与机制问答同步改成「两条路」 | `tools/agent/persona.mjs`、`review_gate.reviewWorkflowMechanismAnswer` |
| 规程与设计稿同步 | `agent-skills/飞书内容审核工作流/SKILL.md` §链接、`docs/superpowers/specs/2026-10-20-feishu-content-review-workflows-design.md` §3.5（附修订注） |

**红线一个字没松**：`/file/` 附件在飞书 OpenAPI 里没有原文读取接口，`download` 是唯一内容通道 ⇒
**不下载、不探测**（`feishu_link.mjs` 里没有任何 `download`/`medias` 调用；
`feishu_link.test.mjs` 用桩全程断言「一次都没碰」）。回复改成：

> 这条链接是飞书云空间附件《【FINAL】Momcozy Wellness 1 红人Brief_职场妈妈版.pptx》，不是文档。
> 飞书对附件没有原文读取接口，按红线「飞书内容禁止下载」我也不取附件，所以这次读不到正文。
> 可以改走：① 把正文（或关键段落）直接贴给我；② 复制到一篇飞书文档里，再把文档链接发我；

## 七、这条不能证明什么

- 不能证明 wiki 节点的正文读取在线上跑通过（两个样本一个 not found、一个无权限 ⇒ 未测）。
- 不能证明旧版 `/docs/` 的读取路径可用（无样本）。
- 不能证明「附件能被审核」——红线是策略，永远不取；本条只保证**话说清楚**。
- 不能证明飞书文档读到的正文足以支撑一次审核（它只保证「正文进链」，判不判得过是链的事）。
- 不能证明线上已生效（未重启）。
