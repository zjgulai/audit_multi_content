## 三、病灶：三态与条目**读成了两个来源**

| | 旧跑手（`.work/run_regression_set.py`）读的是 |
|---|---|
| **三态** | `out["decision"]["decision"]` → `review_engine.decide()` 的产物 |
| **条目** | `--findings-out` 缓存里的 `ev["findings"]` → **`review.py` 的产物** |

而 `decide()` 的输入不是 `findings`——是（`with_kb_evidence.py:1180` ＋ `:1199`）：

```python

payload["risk_items"] += scan_text(text, product_line=product_line_seed, channel=channel)   # ← 无条件并入

两个来源必然对不上——**对不上是读法造成的，不是引擎矛盾**。

⇒ 已落成判据：跑手一律**从结论对象取值**（`decision.decision` ＋ `decision.risk_items`），
证据侧 `findings` 降为**对照**，两者之差分成三类，各归各的性质：

| 字段 | 含义 | 性质 | **100 条实测** |

| `orphan_p3_n` | 证据有、结论没采纳，且 `p_level=P3` | **合法**（§6.3 执行规则3） | **0** |

⇒ 那两个字段**保留作守卫**（将来有人改坏映射就会响），但**它现在守的是空集合**。

## 四、★ 真缺陷：H09 词表少一个字母，红线没响

### 4.1 事实（逐条可复跑）

素材 `RC-11b8f1e6a2c7`（2000 字，Wellness 1 视频脚本）**逐字含**：

```

```python

    "literal": ["mimics baby", "mimics baby’s natural nursing"],
    "synonym": ["mimic baby", "mimics a baby", "imitates baby", "baby-like suckling",
                "模仿婴儿", "模拟婴儿吸吮", "还原婴儿吮吸"],
    "regex": [r"\bmimic(s|king)?\b[^.]{0,30}\bbaby\b",
              r"模仿\s*婴儿|模拟\s*婴儿|还原\s*婴儿"],

```

**三条路一条都不覆盖这句话**：词表里有 `baby-like suckling`（名词形式），
**没有** `baby-like sucking` / `sucking rhythm`；正则要 `mimic` 那个动词。
