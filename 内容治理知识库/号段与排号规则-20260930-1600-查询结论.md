## 1. 分配规则（逐条，可复算）

**格式**：`<库前缀>-<形态段>.<序号>`，例 `W-1.12`、`E-1.375`。

| 规则 | 内容 |
|---|---|
| 前缀 | = **库**（记录的 `kb_type`）。不是文件、不是 form |
| 段号 | = **形态段**，按**每库各自一套**的权威分段表查（不是全局 form→段） |
| 序号 | 在同一 `(库, 形态段)` 内**从 1 起连续**；不跨段、不跨库连号 |
| 库间关系 | **每类库各自一套编号，不全局连号** |
| 排序键 | `kb_type（库）` → `形态段` → **内容派生的稳定不可变 id 升序**（`rule_id` / `case_id` / `clause_id`，后者均为 `sha1(…)[:16]`） |
| 排序键为什么这么定 | 只用规则自身不变量。**不用** `support_count`、风险等级、时间、**文件行序** —— 避免规则增删让已发条款号错位 |
| **永不复用** | 号一经发出**永久占用**。重跑时已在册的 `rule_id` **沿用原号**；新规则取该段 `next_seq`；**即使某条规则后来消失，它的号也不回收、不再发给别的规则** |
| `next_seq` | = 该段已发最大号 + 1 |
| 职责边界 | 号是**稳定标识**，不是版本号。`kb_version` 仍 `v0`，不产生 `release_id` |

> 段内序号实测**无空洞**：五段 `1…max` 全连续、`article_no` 无重复（L4 闸门 C1 复算 1242 条唯一）。

**⚠️ 已废止的表，不许再用**（权威分段表里写死的 `block_by_library_authority`）：

> 旧 `numbering.form_block`（`entry=1 / revision_pair=2 / boundary=3 / saythis=4`）**自 run 20260924-1320 起废止**。
> 它是**全局** form→段 映射，其 `boundary=3` 与 `W-3` **直接冲突** —— 继续沿用会让同一段号指两个形态。
> 旧表只作历史留痕保留，**不得再用于任何新分配**。

**但活台账 `kb/l4/registry/l4.json` 现在恰恰只留了这张废止的旧表，删掉了权威的 `block_by_library`** —— 见 §6。
