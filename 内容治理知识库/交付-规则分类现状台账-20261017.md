## 二、类别含义（表内「11类」sheet 逐字）

### 母婴知识内容准确性（401 条 · 62.9%）

```
内容准确性＝母婴科普的事实是否对：哺乳泌乳、吸奶器使用与母乳储存、孕期产检、产后恢复、睡眠喂养等。
兼收措辞表达类问题＝文字表达、排版、大小写、语法、术语，落在「内容形式与表达规范」27 条；该子类还混着配图、参考文献、适用范围等非措辞项。
```

### 合规与受监管宣称（78 条 · 12.2%）

```
合规＝法律法规与法定要求：法定认证与注册表述、等级与资质背书用语、保险与报销资格、结构功能与免责声明。
受监管宣称＝受监管管制的产品宣称：医疗与疾病功效、生理功效与效果、绝对化与最高级用语、无痛/安全/零风险、临床与科学背书、智能与仿生。
判的是“话本身越不越线”，不看有没有证据。
```

### 证据与实质证明（78 条 · 12.2%）

```
证据＝宣称有没有依据：销量排名依据、临床与科学证据要求、证据不足待验证。
实质证明＝证据够不够硬：研究方法与统计口径、限定语与整体印象是否误导。
```

### 背书与披露透明（31 条 · 4.9%）

```
背书＝专家与专业人士的背书是否成立、资质是否够。
披露透明＝有没有如实说：达人合作与付费推广、利益关系与资质、限定信息与免责声明（须清晰显著）、风险信息、视听形式要求。
```

### 平台与渠道政策（20 条 · 3.1%）

```
平台政策＝平台侧的投放与素材规则：禁投品类与场景、版位与投放形式、平台标识与授权素材、素材提交规范。
渠道政策＝按投放渠道（Google / Meta / 其他）区分的规则。本类仅 1 条带渠道（W-1.7）；「渠道」在表中主要落在「适用范围」列——全表 68 条带具体渠道，散在合规 48、品牌 6、背书 4、商品信息 4、推广 3、证据 2、本类 1。
注：本类 20 条中 19 条无渠道限定，正文实为各国广告禁令（奥地利、新加坡、英国 HFSS、FTC）与素材提交要求，类名与内容不符。
```

### 商品信息与Listing准确性（13 条 · 2.0%）

```
商品信息＝规格参数、功能与部件、产品体验与设计方向。
Listing 准确性＝页面上适配尺码、防漏密封等描述与实物是否一致。
只判“对不对”，不判“合不合规”。
```

### 品牌信任与声誉（8 条 · 1.3%）

```
品牌信任＝slogan、价值主张是否与品牌调性一致。
声誉＝竞品对比是否构成贬低。
不违法但伤品牌，以 P1/P3 建议类为主。
```

### 推广与价格透明（4 条 · 0.6%）

```
推广＝促销话术是否施压或制造虚假紧迫感。
价格透明＝折扣与会员活动的价格表述是否清楚。
```

### 产品安全与高危使用场景（2 条 · 0.3%）

```
产品安全＝产品或用法本身带来的健康风险：儿童乘车与居家防护。
高危使用场景＝危险行为示范与事故高发场景：怀抱乘车、趴睡、无人看护下水、未用安全座椅。
现有 2 条，两个子类各占 1 条。
```

### 权利、肖像、隐私与AI（2 条 · 0.3%）

```
权利＝版权、商标等第三方权利——现有 0 条。
肖像＝肖像授权范围——现有 0 条。
隐私＝未成年人出镜与隐私保护；AI＝AI 生成内容是否标识。这两段各 1 条，均为 P0。
```

### 北美本地化与标签要求（1 条 · 0.2%）

```
本地化＝美国市场的表达、计量单位与育儿语境——现有 0 条。
标签要求＝标签与包装的法定要求——现有 1 条，但正文是巴西（有机标识须落在包装上），不是北美。类名与内容不符，需复核。
```

## 五、边界（照实说）

1. **11 类这套类目不是源表字段、也不是 PRD 原文类目** —— 它是 2026-10-16 会话里由助手（我）提出的分类体系，Owner 采用后落库；`kb/` 内除本次注册表外**没有第二处**定义这 11 类（`grep 合规与受监管宣称 kb/` 只命中注册表）。⇒ 类目的权威性需要 Owner 签字；与库内既有两套类目（`l7.json.vocabulary.categories` 8 类规则词表、`sample_case.reason_category` 7 类反例类目）以及 PRD §5.3 四维（合规/消费者安全/产品描述/措辞表达）的映射**尚未裁**。
2. **`p_level` 有两个读法**：评审链规则层读规则行（＝本表口径）；只看引擎实际读取的 509 条就是 P0 40 / P1 137 / P2 213 / P3 119；L5 侧读 manifest 富化（仍是旧值）。本表按**规则行**统计 638 条（含外部标准 129 条；外部标准不进评审链规则层）。
3. 占比分母统一是 **638**（509 措辞 + 129 外部标准）。若只看评审链实际读取的 509 条，分母换成 509，占比会变。
