## 四、回源锚点怎么补（给接手人的三步）

1. 在飞书那一行上**复制记录链接**（URL 形如
   `https://momcozy-in.feishu.cn/base/<base_token>?table=<table_id>&record=<record_id>`），
   从 `record=` 参数取 `record_id`；同时记下 `base_token` / `table_id` / 表名 / 字段名。
2. 按 `kb/l8/ingest_l0_new_records.py` 的口径把该记录登记进 L0
   （先干跑，看清将写什么，再 `--apply`；该脚本只写新文件，飞书侧全程只读）。
3. 再跑 L1/L2 引擎，**先预演后落盘**：
   ```bash
   kb/kbpy l8/extract_l1_new_resources.py <RUN>            # 干跑
   kb/kbpy l8/extract_l1_new_resources.py <RUN> --apply
   kb/kbpy l8/l2_split_run.py <RUN>                        # 预演：只打印将追加 N 行
   kb/kbpy l8/l2_split_run.py <RUN> --apply
   ```
   验收：`kb/kbpy l7/scripts/l2_gate.py` 退出 0；再预演一次应报 **+0 行**（幂等收敛）。

> 三条红线（来自 `kb-ingest-extractor`）：不许不预演就落盘；台账 append-only，不许删行让闸门变绿；`unit_count` 口径未写死，别在会话里口头约定。
