## 1. 分配规则（逐条）

| # | 规则 | 出处（真源） |
|---|---|---|
| 1 | 格式 `<库前缀>-<形态段>.<序号>`；**序号在同一（库, 形态段）内从 1 起连续** | `l4.json → numbering.format` |
| 2 | **前缀 = 库（`kb_type`）**，不是文件、不是 form | `numbering.library_prefix` |
| 3 | **段号 = 形态段**，按**每库各自一套**的表查 | `numbering.block_by_library` |
| 4 | **每类库各自一套编号，不全局连号** | `numbering.per_library` |
| 5 | 排序键：`kb_type`（库）→ 形态段 → **内容派生的稳定不可变 id 升序**（`rule_id` / `case_id` / `clause_id`） | `numbering.order_key` + `order_key_per_form` |
| 6 | 排序键为什么这么定：**不用** `support_count`、风险等级、时间、**文件行序** —— 免得规则增删让已发号错位 | `numbering.order_key_note` |
| 7 | **永不复用**：号一经发出**永久占用**；重跑时在册 id 沿用原号；新规则取该段 `next_seq`；**即使某条规则后来消失，它的号也不回收、不转给别的规则** | `numbering.no_reuse` |
| 8 | `next_seq` = 该段已发最大号 + 1 | `numbering.issued.*.next_seq` |
| 9 | 号是**稳定标识**，不是版本号；`kb_version` 仍 `v0`，不产生 `release_id` | `version_rule` |

## 2. 前缀怎么定（只看 `kb_type`，不看文件、不看 form）

| 前缀 | 库（`kb_type`） | 库名 | 能否分配 |
|---|---|---|---|
| `E` | `external_standard` | 1_外部标准库 | 可 |
| `S` | `internal_sample` | 2_内部正负样本库 | 可 |
| `W` | `wording` | 3_措辞表达库 | 可 |
| `P` | `product_desc` | 4_产品描述库 | 可（本批 0 条） |
| `X` | `unknown` | 9_未归类 | **`blocked_policy`：永不得分配** —— 先归类再编号 |

**关键：前缀跟"载体文件"不是一回事。实测同一个文件里装着两个库的记录**（本次复算）：

```

  └─ kb_type=wording          157 条  → 前缀 W  → W-3.1 … W-3.157
```

所以 **不能按文件名猜前缀，也不能按 form 猜前缀** —— 只认记录自己的 `kb_type`。
（`scoped_clause` 这个 form 就是例子：外部标准库落 `E-1`，内部样本库落 `S-2`。）

## 5. ⚠️ 两处对前序报告口径的修正 / 补充（本次新增，排号前请以此为准）

### 5.1 「照活台账排号会撞号」要分清两种情形 —— 不是"下一次跑就撞"

前序报告（`排号规则与未发号段-复核-20260930.md` §6.4）说得很重，容易读成"跑一次就撞"。
本次做了**只读复算**，实际是：

| 情形 | 复算结果 | 是否撞号 |
|---|---|---|
| **A. 用现有输入跑现有引擎**（`CAND = rules.jsonl`，1018 行） | 台账里那 509 个 `rule_id` **全部**也在 `rules.jsonl` 里，**新发号 = 0 条、全部沿用** | **不撞号**（但也是空操作，救不回 733、也发不出那 123 条新号） |
| **B. 一旦有新批次真的产出 `W-3` / `S-1` / `E-1` 段**（或有人拿 `sample_cases.jsonl` / `scoped_clauses.jsonl` 从零发号） | 这三段**不在活台账里** → `next_seq.get(seg, 1)` 返回 **1** → 从 `.1` 重发 | **正面撞车**：与 canonical 里在用的 `W-3.1` / `S-1.1` / `E-1.1` … 相撞 |

**结论**：**风险是真的，但触发条件是"这三段再次产出"，不是"随便跑一次"。**
排号恰恰就是"再产出"这件事本身 —— 所以**你要排新号之前，必须先把台账修好**。
