## 五、结论与推荐

- **「不符合就重跑」的条件没有触发**：0 条非美国口径。
- **推荐：不重跑那 72 条。** 代价/前提：账面留一句「72 条出在美国口径规则生效前，已按内容核过 0 条不合规」。
  若你要「整批同一版 prompt」这个更强的口径，那就得重跑 72 条（约 2.5 小时），
  但按实验 B 的读数，**重跑后的差异无法归因**（分不清是规则还是抖动）。
- **推荐做（最省、方向最安全）**：给 prompt 那句「不得援引非美国市场的合规要求」**补一句**
  「**但不得因此删除任何对美国消费者成立的通用问题**（平台图片惯例、英文校对、信息完整性等）」。
  理由：实验 B 里 `8782433452230` 从 3 条掉到 0 条虽然是抖动，但**掉的方向是 fail-open**（该拦没拦），
  值得用一句话把边界钉死。代价：改 prompt ＋ 重启守衡。
