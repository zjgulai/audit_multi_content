**做法**：把 fix 版复制到两个互不可见的隔离目录（`/tmp/kbcheck-probe/fix1|fix2`，

口径与 11:41 那轮 harness 相同（可比）。

**结果（两次一致）**：

| 用例 | 探针 1 | 探针 2 | 框架要求 | 判定 |
|---|---|---|---|---|

**两次的理由原文都指向同一处**：

> 「SKILL.md description 明确列『先追问、不要加载本 skill』清单，其中第②条＝『只打 skill 名』」

```
先追问、不要加载本 skill：① 口令过短/只有名词/指代不明 …… ② 只打 skill 名 ……
```

⇒ **结论**：v1.1.0 的 [53] 失败是"少写了一句"（可补）；**v1.2.0 的 [53] 失败是"写反了一句"**
（必须把「② 只打 skill 名」从"先追问、不要加载"清单里删掉/改写，并声明"只打本 skill 名 ⇒ 先加载再追问"）。
**v1.2.0 在调用门槛上比 v1.1.0 更远，不是更近。**
（fixture 探针，非完整 3 轮真实盲测；两次独立会话结论一致，且与 description 文本自证吻合。）
