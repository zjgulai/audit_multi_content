## 三、★ 没做什么（这条最要紧）

**没有替法务签。** `signer` / `signed_at` / `basis` 一律 `null`，`status` 一律 `pending`。

本库在"不许编"上栽过：**空值人会去补，错值人不会再回头看。**
⇒ 本件的产出是「**夹具就绪 ＋ 待签 11 条**」，**不是**「已确认」。

**怎么签**（逐条改 `legal_signoff`）：
`status` → `confirmed` / `rejected`；`signer` → **具名**（不许写「法务团队」）；
`signed_at` → `YYYY-MM-DD`；`basis` → 依据（法条 / 内部口径 / 会议纪要）；例外写 `note`。
改完跑判据：

```bash
python3 kb/l8/build_p0_legal_signoff_ledger.py --verify
```
**11/11 已确认、且无一条缺具名签署人**，才算 PRD §16 那条应对真落地。
