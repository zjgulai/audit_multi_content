## 1. 怎么查出来判错了（三步，每步可复算）

### 1.1 原改动单的证据是对的，归因是错的

它的 §1 说：待定稿 2780 条 `scoped_clause` 里 `char_count` 落在 **[3800,4000] 的占 90.0%**，
中位 3912 ← 「`TARGET=4000` 的签名」。**这个读数我复算成立**（我在 `scoped_clauses.jsonl` 上量到 77.9%）。

但「像 4000」不等于「是那个脚本切的」。

### 1.2 拿 `rechunk_l1_segments.py` 的判据筛，L1 里根本没有那么多

它只碰 `kb/l1/*/url__*.json` 且 **anchor 必须是 `#正文`**。全库 L1 段 19,798 个里，
「3800–4000 字且不含 `\n`」的**只有 34 段**——而 L3 有 **4056 条**同形态。**差了 100 倍，接不上。**

### 1.3 单条溯源，钉死出身

取一条（`scl-m-015c8c0096caceae`）：

```
anchor      = #亚马逊!A1:T389                        ← 飞书【电子表格】的区域锚点
resource_id = sheets__BX0QshqWThhY6HtDEFCcnMpsnRc
正文头       = '[row=1] ,https://alidocs.dingtalk.com/...'
evidence_units = 0（L2 里也查不到它的 unit_id）
```

而 `kb/l1/<...>/sheets__BX0QshqWThhY6HtDEFCcnMpsnRc.json` 里，段是**一排正好 4000 字**的
`kind=sheet_range`，锚点带 `（续）`：

```

#亚马逊!（续）     长=4000 行数=12
#W1 26年H2 内容地图!A1:T200  长=4000 行数=125
```

⇒ **4000 字的切割发生在 L1 抽取那一步。** `rechunk` 与 `l2_split_run.py`
（它的阈值是 `MAX_UNIT_CHARS=8000`）**都在下游**。

### 1.4 真凶

`kb/l8/extract_office_batch.py`（改前 :231-233）：

```python
CHUNK = 4000                                        # :73
...
```

**对一张表的 CSV 做纯定长字符切** —— 切在行中／格中／词中。

> ★ 顺带更正我自己：中途我曾怀疑是 `kb/l8/l2_split_run.py:138`（同一个字符切模式），
> **那是错的** —— 它的 `target` 默认 `MAX_UNIT_CHARS = 8000`，不是 4000。**已核。**

## 2. 改了什么（都在 `kb/l8/extract_office_batch.py`）

### 2.1 新增 `chunk_on_lines()`（模块级，紧挨 `CHUNK` 常量）

按**行边界**把文本聚合成 `<= target` 的块，**逐字无损**（`"".join(结果) == 原文`）：
除最后一块外**每块都以 `"\n"` 结尾** ⇒ 切点必然是行边界 ⇒ **词中间在结构上不可能**。
只有**单行本身**超 `target` 时才退回字符切（那种行无法再按行分）。

### 2.2 三处调用点全换掉

| # | 位置 | 改前 | 性质 |
|---|---|---|---|
| ① | `sheet_range`（飞书在线表） | `csv[j:j+CHUNK]` | 定长字符切 ← **原改动单要找的就是它** |
| ② | `table`（xlsx 工作表） | `txt[:CHUNK]` | **静默截断**：4000 字之后的行**直接丢** |
| ③ | `image_ocr` | `txt[:CHUNK]` | **静默截断**：OCR 超 4000 字的**直接丢** |
| ④ | `paragraph`（pptx 备注页） | `txt[:CHUNK]` + `txt[k:k+CHUNK]` | 无损但字符切，且**所有块共用同一个 anchor `#s.{n}`**（引用同一锚点指不到是哪块） |

②③ 是**丢数据**，比切碎更严重；④ 是**锚点撞车**。三处一并改为 `chunk_on_lines`
并在多块时给续块区分锚点（②照飞书表的 `（续）` 惯例，③④加 `/{i}`）。

**改的都是「在哪里断开」，不增删任何字符。**
