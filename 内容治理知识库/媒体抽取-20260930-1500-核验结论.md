## 4. 复跑会写什么（幂等键已定，随时可跑）

幂等键：`(resource_id, extractor_version=l1-0.1, source_sha256)`；OCR 缓存另按**文件 sha256** 命中。
**本批 169 个唯一哈希全部命中缓存**，所以 `--apply` 只会重新下载 304 张图并复用缓存正文，
**不会新增任何知识**。除非飞书侧素材变了，否则不必跑。

```bash
cd <内容治理工作区根>
kb/kbpy l8/ocr_attachments.py <OCR_RUN>            # ① 预演（不落盘）
kb/kbpy l8/ocr_attachments.py <OCR_RUN> --apply    # ② 落盘
kb/kbpy l8/apply_ocr_to_l1.py <OCR_RUN> <L1_RUN> --apply   # ③ 回写 L1 台账
kb/kbpy l1/index/rebuild_l1_index.py --write --run <L1_RUN>  # ④ 补 media 单元索引
kb/kbpy l7/scripts/l1_gate.py                                # ⑤ 闸门

```

反例提醒（别踩）：
- `--purge-images` **不是预演开关**，它删的是 L1 工作副本，不是 L0 原图；删库重来一律不接；
- 坏缓存（引擎版本不对 / `sha256_state` 非 full / 正文含 U+FFFF / 整图丢失）不得复用，命中就重跑 OCR；
- OCR 空结果如实登记 `empty` + `status_reason`，不许拿别的字段凑正文；
- 本地散图进不来：引擎不读本地文件夹，输入必须是 L0 已登记的 resource。
