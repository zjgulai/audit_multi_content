# Gotchas —— kb-canonical-lookup（错误 → 修正）

> 由 `_supp-creator-audit-20261004` 补充优化加入（root-skills-creator 清单②③：
> gotchas 用「错误 + 修正」强模式，并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：把 canonical 说成「六个形态文件」
  **修正**：是**五个**形态文件（`wording_entry` 56 / `wording_revision_pair` 453 / `sample_case` 358 / `scoped_clause` 375，共 1365 条）。

- **错误**：查 `kb/l4/canonical/rules.jsonl` 返回空，就说「这条没定稿」
  **修正**：该文件**恒 0 字节**（迁移留痕、不计形态），查它**必然**为空，不能据此下「未定稿」结论。

- **错误**：同一 `rule_id` 出现两个条款号时挑一个报给用户
  **修正**：**报冲突**，两个都列出来，不要替用户选一个。

- **错误**：用户只给半句（「条款号。」）就盘点整层
  **修正**：**先追问是哪条规则**；只有明确对象才做盘点。

- **错误**：本 skill 不处理发号 / 晋升 / 重建 L4，即使措辞看起来相似（「给它发个号」）
  **修正**：全是**写操作**，归 `kb-pipeline` 以层身份调用；本 skill 查询档不给自己开写入口。
