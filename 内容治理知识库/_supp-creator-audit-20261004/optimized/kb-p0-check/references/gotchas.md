# Gotchas —— kb-p0-check（错误 → 修正）

> 由 `_supp-creator-audit-20261004` 补充优化加入（root-skills-creator 清单②③：
> gotchas 用「错误 + 修正」强模式，并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：把「没命中」说成「没问题」
  **修正**：P0 是**最高优先级**口径，**不是合规口径**。未命中只说明不是最高优先级，其余风险走 `kb-review`。

- **错误**：清单里没有的说法顺手归纳成一条新 P0
  **修正**：**不自己造模式**；要加就交 `kb-pipeline` 走链路。

- **错误**：用户问整段内容能不能发，却直接给结论
  **修正**：本 skill 只答「**是不是 P0**」；「能不能发」走 `kb-review`。

- **错误**：P0 模式表为空时用常见违规清单顶替
  **修正**：如实报「**P0 层为空**」，不许拿常识清单冒充库里的模式。

- **错误**：本 skill 不处理条款号查询，即使措辞看起来相似（「这条 P0 的条款号是多少」）
  **修正**：条款号归 `kb-canonical-lookup`；要逐字依据归 `kb-content-review`。
