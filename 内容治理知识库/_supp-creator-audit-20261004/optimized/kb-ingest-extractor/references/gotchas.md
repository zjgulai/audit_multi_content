# Gotchas —— kb-ingest-extractor（错误 → 修正）

> 由 `_supp-creator-audit-20261004` 补充优化加入（root-skills-creator 清单②③：
> gotchas 用「错误 + 修正」强模式，并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：把「切分」当成「合并」
  **修正**：本层 **只拆不合**。跨单元合并属 L3 规则层，本 skill 不做。

- **错误**：`+0 行` / `sha 没变` 报成「跑失败了」
  **修正**：那是**幂等跳过**，是正常态。要如实报「已是最新」，不是失败，也不是没跑。

- **错误**：没给素材就凭「上一批」代选一批开跑
  **修正**：**欠定先追问**要抽哪批、落到哪一层；材料没给全不要开跑。

- **错误**：把 dry-run 当成已经落盘
  **修正**：预演只给「将追加多少行」；写档是另一态，且写档入口在 `kb-pipeline`。

- **错误**：本 skill 不处理图片 / 附件 / 落地页的 OCR，即使措辞看起来相似（「把这批图抽成单元」）
  **修正**：OCR 归 `kb-media-extractor`；本 skill 只接**已经落成文本**的素材。

- **错误**：本 skill 不处理条款抽取与规则蒸馏，即使措辞看起来相似（「把这段政策蒸成规则」）
  **修正**：归 `kb-clause-extractor`（L3）。
