## 二、手机号与 open_id 为什么取不到（是「库里没有」，不是「我没找」）

1. **源字段根本不是人员型。** 源表 `外部资料库__数据表` 的「上传人员」字段定义是
   `{"field_id":"fldiQL5Rgi","field_type":"text","value":"郭嘉"}` —— **`text` 文本型**。
   飞书只有**人员型（`user`）字段**才会带回 `open_id`；文本字段从采集那一刻起就没有 open_id 可带。
   （实测文件：`kb/l0/records/外部资料库__数据表/rec27MOkVYtXZ5.json` → `fields.上传人员`）
2. **全库文本扫描**：`kb/l0` 下 `手机号` / `open_id` **零命中**；canonical 四个形态文件里同样零命中。
   （注意：`sample_case` / `wording_revision_pair` 里的 `phone` 命中共 8 处，逐条看过，
   全是英文/法文营销文案里的「phone / smartphone / Téléphone」—— 手机这个**物件**，不是手机号。）
3. **数据表的 13 个字段里没有这两列**：上传人员 / 主题场景 / 地区 / 链接 / 是否完成医学审查 /
   是否完成合规审查 / 是否需要授权 / 权威层级 / 语言 / 资料名称 / 资料类型 / 适用对象 / 阶段。
