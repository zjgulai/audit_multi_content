# 两段协议细则（检索 / 引用）

本文件是可加载的细则，正文要点在 `SKILL.md`；**口径以 `kb/l7/registry/l7.json` 为准**。

## 一、检索协议

### 四层下探（顺序写死）

| 层 | 命令 / 数据 | 判定 | 备注 |
|---|---|---|---|
| 1 P0 确定性匹配 | `python3 kb/l5/matcher.py --text "<内容>" --json` | 退出码 1 或 `hits` 非空 → BLOCK | 命中即 BLOCK，不走向量；实测单次 11–28 ms |
| 2 规则层 | `kb/l3/candidates/rules.jsonl`（最新一行口径） | `forbidden_expression` 片段在正文里逐字命中 | 规则自带 `article_no`（L4 分配，只读）；`kb_type` 全是 wording |
| 3 单元层 | `kb/l6/retriever.py` 的 BM25（主）/ 向量（补） | 原始分 ≥ 门限 | 见下方"门限" |
| 4 原文层 | `kb/l0/records/<表>/<记录>.json` 的字段值；或 `kb/l0/snapshots/` | 摘录必须在该字段里逐字存在 | 找不到就不引用这条结论 |

### 门限（原始分，不是 RRF 分）

- `bm25_raw_min = 8.0`：A 组（有关联）最低 5.32 / 中位 12.76，B 组（无关联）中位 6.44 / 最高 10.02，
  取 8.0 偏保守。
- `vector_cosine_min = 0.60`：实测唯一能把 B 组全部挡在外面的取值（B 组最高 0.569），代价是 A 组丢 2 条。
- `coverage_bm25_min = 16.0`：判断"知识库认不认识这个主题"（决定 PASS 还是拒答）的 2 倍门限。
- **单一阈值不够**：A/B 两组原始分有重叠，所以**门限 + 规则层命中**才是"依据"；只有门限只能叫"参考"。

### 向量补召的启用条件

仅当 **BM25 原始分最高值 < `bm25_raw_min`** 时才启用向量；启用后仍要"余弦 ≥ 门限 且 同时命中规则层"才算依据。
结论里必须标注本次是否用了向量补召。

### 不得静默降级

读 `kb/l6/registry/l6.json` → `retrieval_capability.mode` / `semantic_recall`：
若为 `bm25_only` / `false`，检索结果与最终结论**必须显式标注"无语义召回"**。

### 拒答（本层职责）

索引层不会拒答（L6 实测 B 组三种模式 hit@3 全 0 却都返回 Top3）。
拒答条件是：无 P0 命中 + 规则层 0 命中 + 单元层最高原始分低于门限（BM25 与余弦都没过）。
拒答文案按 `no_hit_semantics` **原文**，并给：查了什么、用了几种模式、为什么没依据。
**无命中 ≠ 合规。**

## 二、引用契约

- 格式：`《<库名> <版本>》第 <条款号> 条（链接：<url>）`
- 必带：`anchor` + `source_sha256` + 逐字摘录 + `事实/推断` + 置信度
- 库名只能用四类库真实名称（`kb/l0/registry/kb.json` → `dir_map`）：
  外部标准库 / 内部正负样本库 / 措辞表达库 / 产品描述库
- 硬闸门：锚点解析失败、`source_sha256` 对不上、摘录不逐字一致 → **该结论不输出**，记入
  「无法满足引用契约的结论」清单
- 摘录取"包含命中词的最短原文片段"（仍是原文子串），便于人核对，不转述不概括

## 三、失效模式对照（两段协议可分辨）

| 现象 | 归属 | 表现 |
|---|---|---|
| 结论没有条款号 / 没有锚点 / 摘录是转述 | 引用契约段失效 | 有查没按格式引 |
| 结论凭空出现，检索轨迹为空或没跑检索 | 检索协议段失效 | 没查就答 |
