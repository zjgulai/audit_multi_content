## 结论：未过门槛 7 个（不是 3 个）

上一轮（用例中英混写）只有 3 个未过：`brand-text-compliance-review` / `brand-ai-provenance-rights-review` / `brand-video-safety-review`。

**纯中文用例下多出 4 个**：`brand-content-review-agent`(0.843)、`brand-review-decision-engine`(0.896)、`brand-review-report-memory`(0.889)、`brand-image-safety-review`(0.657)。

**唯一根因**：`kb-content-review` 的 description 明写中文泛化触发词（审查 / 审一下 / 能不能发 / 会不会违规 / 能过审吗 / 有没有风险 / 踩线），而这 13 个 brand-* 的 description 全是英文、**一个中文触发词都没有**。65 个用例 3 轮共 195 次判定里，`kb-content-review` 抢走 **45 次**。
