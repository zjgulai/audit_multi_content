## 1. 分配规则（逐条）

**格式**：`<库前缀>-<形态段>.<序号>` → `W-1.12`、`E-1.375`
来源：`kb/l4/registry/l4.json → numbering.format` / 备份台账同名字段 / `kb/l7/registry/l7.json → article_no_source.format`

| 规则 | 内容 | 出处 |
|---|---|---|
| 前缀 | = **库**（记录的 `kb_type`），不是文件、不是 form | `numbering.library_prefix` |
| 段号 | = **形态段**，按**每库各自一套**的权威表查 | `numbering.block_by_library` |
| 序号 | 同一 `(库, 形态段)` 内**从 1 起连续**；不跨段、不跨库连号 | `numbering.format` |
| 库间关系 | **每类库各自一套编号，不全局连号** | `numbering.per_library` |
| 排序键 | `kb_type（库）` → `形态段` → **内容派生的稳定不可变 id 升序**（`rule_id` / `case_id` / `clause_id`） | `numbering.order_key` + `order_key_per_form` |
| 排序键为什么这么定 | 只用规则自身的不变量。**不用** `support_count`、风险等级、时间、**文件行序** —— 避免规则增删让已发条款号错位 | `numbering.order_key_note` |
| **永不复用** | 号一经发出**永久占用**。重跑时已在册的 id 沿用原号；新规则取该段 `next_seq`；**即使某条规则后来消失，它的号也不回收、不再发给别的规则** | `numbering.no_reuse` |
| `next_seq` | = 该段已发最大号 + 1（已发段实测：`W-1`→57 `W-2`→454 `W-3`→158 `S-1`→202 `E-1`→376） | 备份台账 `issued.*.next_seq` |
| 职责边界 | 号是**稳定标识**，不是版本号。`kb_version` 仍 `v0`，不产生 `release_id` | `version_rule` |

**⚠️ 已废止的表，不许再用**：

> 旧 `numbering.form_block`（`entry=1 / revision_pair=2 / boundary=3 / saythis=4`）**自 run `20260924-1320` 起废止**。
