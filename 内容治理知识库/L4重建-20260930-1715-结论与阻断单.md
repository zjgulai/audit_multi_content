### 4.2 「重新发号」被本层契约明文禁止

台账 `numbering.no_reuse` 原文：

> 号码一经发出永久占用：重跑时已在册的 `rule_id` 沿用原号；新规则取该段 `next_seq`；
> **即使某条规则后来消失，它的号码也不回收、不再发给别的规则**。

而 canonical 里**在用**的号有 1242 个，台账只记得 509 个：

```

台账还记得      509 个（W-1:56 W-2:453）
★ canonical 有、台账无   733 个  ← 全部是 E-1 / S-1 / W-3
```

**「清台账重新发号」= 让 `E-1.1`／`S-1.1`／`W-3.1` 从头发一遍，正面撞上 canonical 里仍在用的号。**
C1（条款号唯一）届时才会转红，而那时已经晚了。
