## 一、PRD 原文（rev 101，逐字）

取数：内嵌 spreadsheet `B1aUs2Vuah8YwjtwWO6cr5MFnUd` / sheet `xcdTpv`，`A1:C5`，**revision 101**
（同日早些是 rev 96）。快照：`_prd-20261019/sheet-xcdTpv-rev101.json`。

| 状态 | 定义 | 系统流转动作 |
|---|---|---|
| PASS | 未发现已知底线风险。可包含 SUGGEST 建议。 | 转 sign-off / brief 提交方。 |
| SUGGEST | 非强制性问题（措辞优化、轻微常识瑕疵等）。作为 PASS 的附属标签，不阻断流程。 | 随 PASS 一起流转，提示内容方。 |
| REVIEW | 存在边界模糊、需专业判断的问题。 | 转法务/医学/专家/北美复核。 |
| BLOCK | 命中明确红线（P0级），或 P1/P2 中证据确凿的违规。 | 返回内容方修改后重新提交。 |

**五处同向 ⇒ `decision` 三值 ＋ 一个标签**：§5.3.2 rev101（附属标签）／§6.3 规则4（「只有 SUGGEST 时，最终状态为 PASS（附 SUGGEST 建议）」）／
§10.1（`decision`：PASS / REVIEW / BLOCK）／§11.2（准确率 = **三态**一致数）／§10.2 注（「SUGGEST 随 PASS 流转，不计入人工复核工单」）。

**「四态」= 统计桶**，不是 `decision` 四值：`PASS ／ PASS＋SUGGEST ／ REVIEW ／ BLOCK`。
判定式：`PASS+SUGGEST ≡ decision=PASS ∧ suggest_count>0`（机器可读字段：`suggest_label`）。
