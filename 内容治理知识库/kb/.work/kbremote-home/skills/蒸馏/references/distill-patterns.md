# 七类素材的蒸馏路线

同一段素材，类型不同走不同蒸馏法。**同一个素材常常混编多条路线——按段落路由，不要整篇走一条。**

---

## 路线总表

| 路线 | 本质 | 适用 | 产出形态 |
|---|---|---|---|
| 方法论蒸馏 | 信息源 → **可执行判断工具包**，不是摘要 | 会议、书籍、结构清晰的文章 | 触发条件 + 执行步骤 + 边界 |
| 人格克隆 | 双轨提炼，**只取决策框架** | 专家经验、某人的判断 | 决策模型（不要模仿语气） |
| 工程操作蒸馏 | 多模态资源 → **可运行的工程 Skill** | 教程、代码、操作录屏 | 可执行步骤 + 可运行代码 + 溯源路径 |
| 棘轮优化 | 已有 Skill 的维护 | 迭代现有 Skill | 走 `root-skills-opt`，不是本技能 |

---

## 1. 会议纪要 + 逐字稿

**提取重点**：取舍、边界、反例、"什么情况才算过"。

- 妙记章节时间戳是天然的出处锚点，**每条判断都要带时间戳**
- 区分"谁说的"和"大家的共识"——前者是观点，后者才够"≥2 处独立佐证"
- **会议里的"要做什么"大多是事实，不是判断**；真正的判断藏在"为什么不那样做"里

**坑**：把待办事项当成判断。待办是事实（下周要做 X），判断是"做 X 时先看 Y"。

---

## 2. 白板手写

**提取重点**：结构关系与箭头方向。

- 箭头方向就是判断（顺序不可颠倒）
- 圈红、加粗、重复标注的块 = 强调，优先级高
- **字迹不确定必须标注，不得猜测**——白板识别错误会被固化成团队标准

**坑**：把缩写当已知术语。白板上 `e-1`、`3:1` 这类没在会上展开的标记，**记为待确认项**，不许猜。

---

## 3. 逐字稿 / 音视频

**提取重点**：口语里的反复表述。

- 同一件事被不同人用不同说法讲了 2 次以上 → 强候选
- 语气词、"呃""就是说"要清掉，**但不要替他润色成他不可能说的话**
- 转写错误要标出来，不要静默修正（修错了就是编造）

---

## 4. 论文 / 长文档

**提取重点**：判断与边界，**不是摘要**。

- 只提"作者主张什么、在什么条件下成立、什么条件下不成立"
- 综述性内容大多是事实，不进正文
- 图表里的结论要能追回图号

**坑**：把摘要当 Skill。摘要回答"这篇讲了什么"，Skill 回答"遇到 X 该怎么做"。

---

## 5. 专家 / 某人的经验判断

**只取决策框架，不模仿语气。**

- 要的是"遇到 X 时先看 Y"
- **不要**模仿口头禅、语气、人格
- 越像某人的 Skill，越容易产生从未存在过的"名人语录"——**三重验证是唯一防线**

---

## 6. 教程 / 操作录屏 / 代码仓库

**提取重点**：可执行步骤 + 可运行代码 + 溯源路径。

- **代码字段必须真跑过**（额外验收谓词 `code_executable`）
- 录屏里的隐式操作（默认参数、环境准备）要显式写出来，否则别人复现不了
- 溯源到具体 commit / 文件路径 / 行号，不要只写"仓库里有"

---

## 7. 聊天记录

**提取重点**：反复出现的决策模式。

- 一次性的对话不蒸
- 只看"同样的问题被问过 3 次以上"的模式 → 这才是入口判据的"会重复"
- 责任主体要标清楚：谁要求的、谁拍板的

---

## 混编示例

一场会议里同时有：

| 段落 | 路线 |
|---|---|
| 讲了开发流程 | 方法论蒸馏 |
| 某人讲了他在某项目上的判断 | 人格克隆（只取决策框架） |
| 演示了一段代码/命令 | 工程操作蒸馏 |
| 白板画了链路图 | 白板路线（简化版方法论） |

**按段落路由**，不要整场走一条路。

---

## 每类素材都要产出「素材总览」

阶段 0 的产出，四步拆解：**结构 / 解释 / 批判 / 应用**。

| 步 | 问什么 |
|---|---|
| 结构 | 素材按什么顺序/框架讲的？分几块？ |
| 解释 | 每块在说什么？核心主张是什么？ |
| 批判 | 哪里自相矛盾、哪里没讲透、哪里只在特定条件下成立？ |
| 应用 | 这些内容在什么场景下会被用到？ |

**"批判"这一步不能省**——它同时给你三类高价值候选：反例、边界、待确认项。

---

## 8. 笔记（读书 / 听课 / 复盘 / 随手记）

**提取重点**：判断与边界，**不是内容摘抄**。

- 笔记里"记下来的事实"大多不用蒸；要蒸的是**你自己在旁边写下的那句判断**（"下次遇到 X 要先用 Y"）
- 同一个道理在笔记里被重复标注两次以上（星号、下划线、反复提）→ 强候选
- 摘抄型笔记（整段抄书、抄课件）**先判入口**：提不出判断就不蒸，如实说明

**坑**：把笔记整理当蒸馏。笔记整理产出的是"更好读的笔记"，蒸馏产出的是"遇到 X 时先看 Y"。
