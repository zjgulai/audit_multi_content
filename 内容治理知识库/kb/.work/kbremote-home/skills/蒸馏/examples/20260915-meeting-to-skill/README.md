# 样例：用 2026-09-15《Agent开发全流程及技能体系讲解》会议蒸一个 Skill

> 一个**真跑过**的完整样例。看每一步的产出长什么样、闸门怎么判的、**淘汰了什么以及为什么**。
>
> 素材：飞书智能纪要 + 妙记章节 + 现场白板 2 张。

## 这个样例演示了三件事

1. 三重验证怎么把一段"看起来全是干货"的会议**淘汰掉 68%**；
2. 白板识别不确定时怎么标（不猜）；
3. 蒸出来的 Skill 怎么交给 root-skills 家族，而不是自己评分。

## 最后蒸出来的是什么

`agent-flow-judgment`（判断集）：**Agent 开发流程里那些模型默认会做反的判断。**

注意：蒸出来的**不是"开发流程"**——流程是常识，裸模型背得出。蒸出来的是**流程里反共识的那几条判断**。

这正是本技能的核心纪律：**只抄结论不抄判断，换场景立刻失效。**
