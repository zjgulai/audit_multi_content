# 漏项模式：Release 第 9 项被写成 fail

如何发现：`validate_report_data()` → `_release_checklist_track_b_errors()`。
当 `track_b.distribution` 正例/负例/近似命中/边界情况均 >0 且 `rounds` 已执行时，第 9 项 `status: fail` 即报错。

从哪补：本轮 YAML 的 `track_b.distribution` + `rounds`，不是 `tests/` 目录声明。
禁止证据：「tests/ 未在正文声明」「无 positive/negative」（第 9 项看本轮 A 卷，不是历史 RED；历史 RED 是第 3 项）。

回填模板：
```
status: pass
evidence: 本轮 A 卷四类已执行：正例N / 负例N / 近似命中N / 边界情况N，3 轮盲测已跑完（track_b.distribution + rounds）
```
