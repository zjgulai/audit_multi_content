# W1 卖点护照：W1-02

**卖点ID**：W1-02

**核心卖点**：五区吸震同步按摩

**用户真实痛点**：泵出停止但仍有充盈感；需要手压/按摩辅助；担心排乳不充分。

**W1设计逻辑**：在真空吸乳之外加入局部节律按摩，模拟亲喂中真空与周期性压力协同的方向。

**现有证据能支持**：亲喂不是单一负压；真空+局部压力/乳房按摩可能改善短时奶流或乳汁移除量。

**推荐表达**：吸乳过程中加入节律按摩，作为辅助排乳和提升舒适体验的设计。

**不能说/谨慎说**：不能说五区对应五条固定乳腺管、一定减少残余奶、治疗堵奶或提高长期奶量。

**证据强度**：中等偏方向：机制合理，按摩方向有证据，但缺W1五区同步对照。

**下一步验证**：比较五区同步/异步/无按摩；测短时移除量、PAMR、泵后充盈感、疼痛和使用偏好。

**适合内容场景**：“为什么泵奶时还想手压”教育文；W1功能FAQ；舒适排乳专家解释。
