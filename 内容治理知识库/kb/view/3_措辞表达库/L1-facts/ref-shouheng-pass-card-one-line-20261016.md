# PASS 单只留一句话结论（2026-10-16 · Owner 裁定）

> 与 `ref-shouheng-card-fields-and-na-20261016` 的关系：那一条修的是「**（未填）与读数别上卡**」，
> 本条接的是 Owner 看到修好之后的那张卡给出的**下一步裁定** —— 他连**模型那句原话**也不要了。

---

## 〇、Owner 原话（逐字）

看到修好的那张 PASS 卡之后：

> 「**只需要一句话结论，去掉『DeepClean Lite 教程』和证据**」

他指的是卡面的第二行（模型那句 `「DeepClean Lite 教程」视频封面：链侧 PASS/0；本轮无合并稿`）
与下面那个 `证据 · 7 条` 折叠区。

**⇒ PASS 单的卡面 = 只有抬头那一行。**

## 一、改法：在**卡这一层**收口，不在 `data` 层

新增导出纯函数 `envelope.mjs::passOnlyLine(card, verdict53)`：把 `card.body.elements` 收成 `[]`。

**为什么不在 `data` 层清**：`cards.mjs` 的 `query-answer` 构造器**恒定**推一个 `md(s(d.verdict))` ——
清空 `verdict` 只会印出 **`（未填）`**（那正是 FIX-037 刚修掉的东西）。
在卡这一层动刀**与构造器无关**；`validateCard` 只要求 `body.elements` **是数组**（空数组合法），
`capSections` 对 0 段是空操作。

**四条边界（缺一条就会伤到别的卡）**：

1. **只认权威结论行给的态** —— `verdict53.state === 'PASS'` 且 `line` 非空。
   闲聊、链没跑成（`verdict53` 为 null）、**REVIEW / BLOCK 一个字不动**
   （它们的逐条块是 PRD §5.3.2+ 的格式件；§5.3.1 才是「只有一句话」）。
2. **砍的是卡面，不是内容** —— 收掉的块逐条记进 `moved`（`field: 'cardBody'`，带字数与去向）；
   原文仍在模型那一轮的回复里（会话记忆 ／ 批跑留档 `dm_ou_batch_runner.json`），
   报告与表行照旧是全份 —— 「搬是搬，砍是砍」。
3. **本来就没有正文 ⇒ 不记一笔**（`stripped: 0`），否则日志会把「什么都没砍」说成「砍了 N 块」。
4. **「抬头归权威结论行 ⇒ 原抬头补进正文首行」那一跳整跳跳过**（`!passOnly` 门）——
   它会把模型那句搬进正文，而现在正文整块不上卡 ⇒ 做了会写出一条**假的搬迁记录**。

## 二、连带影响：**4 条老判据与这条裁定直接冲突**（这一段最该被后人读到）

改完之后 `verify_cards` 立刻红了 4 条，**全是 PASS 态夹具**、断言「模型的话在**卡面**上」：

| 判据 | 它守的是什么 | 冲突点 |
|---|---|---|
| J13a3b2 混排 | 读数摘干净 · 模型按口径写的边界声明一句不许丢 | 边界声明现在**不在卡面** |
| J13a3c 反向对照 | 链跑挂时模型那段是真答复，不许被吞 | 同上 |
| J13a3e | 模型写的话与它给的抬头一句都不许丢 | 同上 |
| J13a3e2 反向对照 | 没声明 `machineAnswer` 时读数一行都不许摘 | 卡面空了 ⇒ **量不到「摘没摘」** |

**处理方式（这一步不能省、也不能糊）**：这四条真正守的是
「**清洗没把模型的话吞掉**」，**不是**「它必须印在卡上」。
⇒ 把「不丢」那半的断言从**卡面**改成 **卡面 ＋ 数据**（`r.card` ＋ `r.data`）：
印不印在卡上由 §5.3.1 与 Owner 那条裁定管；**丢没丢**仍由这四条管（一个字没放松）。

> ★ 另一处同类处理：**J13a3f 那一组的夹具原本用的就是 PASS 态** ——
> 卡面被收空之后，它那几条断言（字段名认得出、读数摘净、模型原话还在）会**全部空转**
> （卡面本来就空，怎么都绿）。⇒ **把它的 `verdict53` 改回 REVIEW**，
> 让「清洗」这一组继续在活着的卡面上受测；PASS 收口另立 J13a3g 那一组。
> **这是本次最容易漏的一步**：判据全绿不等于还在测东西。

## 三、判据（`verify_cards` 新增 J13a3g 四条）

| 判据 | 断言 |
|---|---|
| **J13a3g** | PASS 单卡面**只许那一行** ＋ `body.elements` 必须是空数组 ＋ `moved` 里必须有 `cardBody` 记录（**砍了什么要看得出**） |
| **J13a3g2** | 反向对照：**REVIEW 不许被一起收空**（正文与模型原话都还在） |
| **J13a3g3** | 反向对照：**没有权威结论行**（闲聊 ／ 链没跑成）⇒ 一个字不动 |
| **J13a3g4** | 纯函数四态：PASS 且有正文 ⇒ 收；非 PASS ／ 无结论行 ／ **本来就没有正文** ⇒ 不动、不记账 |

**变异自证两条，逐条精确变红**（真造一遍、还原后 sha256 一致）：
① `passOnlyLine` 改成「凡评审单一律收空」（不看态）⇒ **J13a3g2 ＋ J13a3g4** 变红；
② 把收口那一跳整跳拆掉 ⇒ **J13a3g** 变红。
