# 模型侧的「美国区」：菜单挡住了，解析也必须挡

## 一、模型侧七跳

① 攒读数（本机 OCR ＋ 画面层；视频加抽帧 OCR 与转写）→ ② 拼提示词（硬约束 1–7，第 6 条给来源菜单、第 7 条只审美国市场）→ ③ **一次** LLM 调用（`temperature: 0`、**不带工具**，实测 `tools=无｜max_tokens=8000`）→ ④ 宽容解析 + 逐条验 → ⑤ **把 id 换成链接**（模型只许点 id、不许写 URL）＋ 关键词匹配挑条款位置 → ⑥ 与库侧合并（同位置同类目取交集／不同走并集／冲突降 REVIEW／仅模型侧不单独定 BLOCK）→ ⑦ 渲染卡片与报告、投文档与落表。

## 二、登记表：US × 15 ＋ UK × 2

- **US 15** ＝ 联邦监管 4（FDA S11–S13、FTC S14）＋ 平台政策 11（Amazon S1–S6、Meta S7/S8、Google S9/S10、TikTok S17）；
- **UK 2** ＝ S15 MHRA、S16 ASA/CAP（`辖区层级: 域外监管`，备注写着「按提示词第 7 条不得作为本项目判据，故不进模型侧菜单」）；
- 平台政策那两条（S7/S17）的 `辖区备注` 逐字写着「文本为全球版；按**美国站**适用」；
- **表里没有任何州法来源** ⇒ 与「美国区 ＝ 美国联邦 ＋ 美国平台政策，不含州法」一致。

## 三、缺口与修法

**缺口**：菜单只列美国（15 条），但「把 id 换成链接」那一步仍认登记表里任何 id ——
实测 `basisText({source:'S15'})` **照样把 MHRA 的英国链接挂上去**并标成「登记来源」。
**能递到它面前的**与**能被挂上报告的**不是同一个集合 ＝ 只关了半扇门。

**修法**：口径统一成 `辖区 === 'US'`；非美国 id 与未知 id **同样 fail-closed**（不给链接）。
两支**不许混成一支**：未知 id 是「没给来源」；非美国 id 是「给了、按美国口径不作数」——
后者**照实写进报告**（点了哪个 id、辖区是什么、为什么不给）并**落台账**
（`PMO/logs/nonus-cite.ndjson`）。**丢弃不留痕＝静默消失**。
解析抽成纯函数 `basisTextOf(sources, f)`（显式接收来源表），否则「挡住它的是不是辖区」证不了。

## 四、判据

`ext_basis.mjs --selftest` **32/32**（新增 7 条）：S15/S16 不给链接且 `kind=non-us`（与未知 id 能分辨）；
报告行照实写；**留痕 +2**（自证把台账指到 `/tmp`，真台账不写）；
**反向对照①** S15 辖区改 US ⇒ 又挂得上链接；**反向对照②** S99 仍走原来那支且不落台账。
