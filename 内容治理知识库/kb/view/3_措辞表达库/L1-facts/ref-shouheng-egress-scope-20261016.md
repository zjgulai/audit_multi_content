# 出机器的口径：画面层 ＋ 文字读数

- 端点：`https://api.deepseek.com` ／ `deepseek-flash`（启动横幅逐字 `llmBaseUrl` / `llmModel`）；
- **文字读数出机器**：**500 单**（盘上每份合并报告一单）—— 素材文字（OCR 图上文字、素材正文、口播转写）随**内核与模型侧两次调用**发给该端点；
- **图/帧出机器**：其中 **56 单**（判据：报告里有 `**图 N**（NNNNms` 那种真读数行）；
- 本机不出机器：OCR 认字（macOS Vision）、抽帧（ffmpeg）、语音转写（on-device）、知识库检索与规则（`127.0.0.1:4401`）。
