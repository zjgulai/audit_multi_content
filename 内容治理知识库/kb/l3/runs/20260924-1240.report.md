## 9. 自主决策
| `rule_eligible` 的 `false` 如实落成 **2** 条（记录 + 继承子资源），报告同时给记录级的 1 | 任务同时要求「子资源继承」与「false == 1」；只有只看记录级才同时成立。按继承语义落库更正确，两个数都给 |
| R1 只诊断、不修，也不回改任何 kb_type | 任务明确「本件先只做诊断与留痕，不要擅自改 R1」 |
| 对账选「改口径」而非「改数据」 | 187 个单元确实既产出又被拒；删掉那 187 行 rejected 会丢失「为什么不重复」的原因留痕 |
| `evidence_units` 的 959 个重叠不修 | 它们既是规则依据、又在 rejected 里，语义一致；已在报告与 registry 写明 |
| 判据 A 只校验**在库**记录，排除 125 个 gone 留档文件 | 判据说的是「每条**登记记录**」；gone 留档是同源老 schema 快照，算进去会造出 125 的假缺口 |
| `attachment_refs` 放在同一行 | 任务给了二选一；同一行便于消费方一次读全，且不新增文件 |
