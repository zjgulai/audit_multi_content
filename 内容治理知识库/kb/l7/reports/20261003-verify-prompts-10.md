# 新会话验证 · 10 个提示词（**裸问版** · 2026-10-03）

**不需要任何"尾巴"了。** 层前置（L4/L5/L6 逐层 skill + L7 闸门）、元数据、发飞书，
现在都由 **skill 正文 + 引擎默认** 完成：用户只丢"一句话 + 素材"，链路自己走完。

把下面**每一整段**原样丢进新会话即可（一段就是一条用例）。

---

**① 全链路基线（多命中文字）**
```
这条 Amazon listing 能过审吗？不合规就给我打回。
Momcozy Wearable Breast Pump — FDA certified, hospital grade, painless pumping, 100% safe, no leaking, doctor recommended
```

**② 干净文案（低命中）**
```
这句广告语能不能发？
Momcozy 穿戴式吸奶器，三种模式九档吸力，单双边可选。
```

**③ 认证范围（应让位「产品宣称核验」）**
```
我们的吸奶器到底能不能说「FDA 认证」？这句话能不能上 listing？
Momcozy 吸奶器已通过 FDA 认证
```

**④ 绝对化用语（应让位「文案合规审查」）**
```
这批主图文案有没有踩绝对化用语的线？
美国第一吸奶器品牌｜100% 安全｜永不漏奶｜零疼痛
```

**⑤ 美国本地化（应让位「美国本地化审查」）**
```
这段给美国妈妈看的文案读着别扭吗？单位对不对？
每次吸出约 300 毫升，相当于 10 盎司；请把奶瓶放进消毒柜消毒 30 分钟。
```

**⑥ AI 披露与肖像授权（应让位「AI溯源与权利审查」）**
```
这条达人素材用了 AI 换脸、也没标 AI，画面里还有未打码的孩子，有风险吗？
30 秒达人短视频：画面为 AI 换脸的育儿博主口播，背景有一位未打码儿童；素材由第三方 MCN 提供，授权书暂缺。
```

**⑦ 图片 + 图上文字（应让位「图片安全审查」）**
```
审一下这张主图能不能上架，图上文字也一起看。
主图：白底吸奶器产品图，右上角贴纸写「FDA Approved」；画面左下角有一位宝宝躺在成人床上睡觉。
```

**⑧ 视频口播 + 时间码（应让位「视频安全审查」）**
```
这条 15 秒短视频能不能投？口播和字幕都在这。
00:00-00:05 口播「医院级吸力，跟宝宝亲喂一样」；00:05-00:10 字幕「100% 无痛」；00:10-00:15 画面出现宝宝独自在沙发上。
```

**⑨ 一批素材全流程（应让位「内容审查总控」）**
```
这批素材下周要一起上线，走一遍发布前审查，给我一个统一结论。
(a) 文案：FDA certified, hospital grade；(b) 主图：图上写「No.1 in US」；(c) 15 秒短视频：口播「零疼痛」。
```

**⑩ 边界负例（库里查不到 → 不许硬凑、不许假发）**
```
帮我看看这个马克杯好不好看，顺便写一句爆款文案。
产品：陶瓷马克杯，白色，350ml。
```
**期望**：明说「知识库查不到 / 与本库不相关」，**不编条款号、不发飞书**。
它要是照样给了三态结论或照样发飞书 —— 那就是**硬凑**，是本条要抓的缺陷。

## 怎么判「真的自动跑通了」

1. 回复里有层前置 BASE（`<YYYYMMDD-HHMM>-L4/-L5/-L6`）且**三条审计红 0**；
2. 结论带 `review_id` + 逐条 `条款号 / anchor / source_sha256`（引擎产出，非手搓）；
3. **自动出现飞书两件**：docx 链接（打开**第 1 行就是报告标题**）＋ 表行记录号（`状态` 与结论一致）——
   你没说"发飞书"，它也该有；
4. 它**没问**你要 内容 ID / 渠道 / 版本 —— 表里那几列应是 `AUTO-<hash前12>` / `未指定` / `v1.0`；
5. 拿到 `NEEDS_INPUT（层前置缺失…）` ⇒ 它**跳过了驱动循环**；只给本地报告、没有飞书链接 ⇒ 它**没走发布件**。

## 三条纪律

- **同一时间只跑一个会话**（库锁会互撞，2026-10-03 实测过）。
- 内容 ID 现在**自动生成**（`AUTO-<content_version 前 12 位>`）：**同一段素材重复审 = 覆盖同一行**，
  不同素材天然不同行 —— 不用再手工编号。
- 想清场：删行的命令与删文档的命令见 `kb/l7/reports/20261003-feishu-write-probe.md` §六。
