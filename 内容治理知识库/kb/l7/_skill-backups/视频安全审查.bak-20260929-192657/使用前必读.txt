给业务同事：这个技能要用中文斜杠调用（/视频安全审查）。
DSH 默认不认中文技能名，必须先从 npm 安装中文名补丁 dsh-chinese-skill-patch，否则 / 调不到。

请按这个顺序做，只需做一次（一台电脑装一次即可）。先检查是否已安装，已安装则跳过，不用重复安装：

1. 双击本文件夹里的「安装中文调用名.command」
   （若提示无法打开：右键 → 打开）
2. 等终端显示安装成功
3. 完全退出并重新打开 DSH Desktop
4. 把整个「视频安全审查」文件夹安装为本地技能
   （或拷到 ~/.dsh/skills/视频安全审查）
5. 新开一个会话，输入：/视频安全审查

说明：
- 先检查是否已安装，已安装则跳过，不用重复安装；已装过补丁不要再双击安装脚本
- 补丁优先从 npm 安装 dsh-chinese-skill-patch；脚本自带 vendor/ 离线副本，仅当 npm 不可达时退回使用
- 脚本会自动装到本机已有的 desktop、web 两个 profile
- 不装补丁、只装技能，中文 / 调用会失败

这个技能管什么：美国市场品牌视频的发布前安全与合规审查（画面安全、产品用法、背书、AI 生成、平台风险），结论给 PASS / REVIEW / BLOCK / NEEDS_INPUT。
不管什么：纯文字文案（走 文案合规审查）、图片（走 图片安全审查）、产品宣称真伪（走 产品宣称核验）、美国本地化（走 美国本地化审查）、AI 披露与授权（走 AI 溯源与权利审查）。
