# 视频安全审查（Brand Video Safety Review）

美国市场品牌视频的发布前安全与合规审查。以转写、OCR、镜头、关键帧、音画对齐与时间码为证据，判定安全、产品、背书、AI 与平台风险。

- **中文斜杠调用**：`/视频安全审查`
- **英文原名**：`brand-video-safety-review`（机器 ID，保持不变）
- **对应产出**：每条发现带起止时间码 + 转写或画面证据 + 输入视频哈希；结论为 PASS / REVIEW / BLOCK / NEEDS_INPUT

## 装法（业务同事看这里）

见同目录的 `使用前必读.txt`。顺序是：装补丁 → 完全退出并重开 DSH → 装技能 → 新会话输入 `/视频安全审查`。

## 不适用

纯文字文案合规（走 文案合规审查）、图片静态风险（走 图片安全审查）、产品宣称真伪（走 产品宣称核验）、美国本地化与计量单位（走 美国本地化审查）、AI 生成披露与肖像商标授权（走 AI 溯源与权利审查）、只问一段内容能不能发而不涉及视频画面（走 kb-content-review）。
