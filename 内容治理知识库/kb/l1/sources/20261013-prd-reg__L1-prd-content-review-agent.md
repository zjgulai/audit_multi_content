设计背景</h3><p></p><p>不同规则类型对模型推理的需求、响应速度和审查准确率要求差异显著。法务合规类规则命中即需拦截，常识性错误需要语义理解，措辞规范相对可容忍。如果不做分层，所有规则走同一推理链路，会导致两个问题：一是法务红线规则被模型“过度推理”后误判为不违规，二是大量低风险内容消耗模型算力、降低整体吞吐效率。</p><p></p><p>行业内容审核的通行做法是采用<b>漏斗式分级过滤</b>：第一层快速拦截（关键词、规则引擎），第二层深度推理（大模型语义理解），第三层人工复核。轻量规则先跑，大模型算力只用于真正需要深度理解的少数内容。</p><p></p><h3>6.2 REVIEW<br/>    └── 未发现 → 进入第四层<br/>    ↓<br/>第四层：P3 措辞与表达建议<br/>（大模型生成建议）<br/>    └── 输出优化建议（不影响 PASS/BLOCK 结论）<br/>    ↓<br/>汇总三态结论</code></pre><p></p><p><b>执行规则</b>：</p><ol><li seq=\"1\" seq-marker=\"1. \">P0 命中即停止后续审查，直接输出 BLOCK，确保法务红线零延迟拦截。</li><li seq=\"2\" seq-marker=\"2. \">P1 与 P2 可并行执行，按最高风险等级输出结论。</li><li seq=\"3\" seq-marker=\"3. \">P3 仅输出建议，不改变 PASS/BLOCK 结论。</li><li seq=\"4\" seq-marker=\"4. \">当多条规则同时命中时，按最高优先级输出；例如同时命中 P0 和 P2，结论为 BLOCK，报告中列出全部问题供参考。<p></p></li></ol><h3>6.4 行业实践依据</h3><p></p><p>内容审核行业的核心做法是“规则优先级分层 + 分级匹配”：</p><p></p><ol><li seq=\"1\" seq-marker=\"1. \"><b>权重分配</b>：将规则分为硬性规则（违法违规内容）和软性规则（低质量文本），硬性规则权重最高（例如权重 10），软性规则次之（例如权重 5）。<p></p></li><li seq=\"2\" seq-marker=\"2. \"><b>分级匹配</b>：第一层高频硬性规则快速匹配（关键词黑名单），匹配成功立即处理；第二层低频软性规则异步检测（语义分析），降低延迟。先用正则匹配敏感词（毫秒级响应），再调用 NLP 模型分析语义（秒级响应）。<p></p></li><li seq=\"3\" seq-marker=\"3. \"><b>冲突解决</b>：当多条规则同时命中时，采用“最高权重优先 + 人工复核兜底”模式。例如，一条内容同时命中广告规则（权重 50%）和涉政规则（权重 90%），系统优先拦截涉政内容。<p></p></li><li seq=\"4\" seq-marker=\"4. \"><b>漏斗式三层架构</b>：第一层快速拦截（关键词、规则引擎和轻量模型），第二层深度推理（中高风险内容进入大模型审核层），第三层人工复核（边界模糊、高敏感度内容）。<p></p></li></ol><p>本 PRD 的 P0-P3 四层设计即基于上述行业实践，结合母婴品类审查场景做了适配。</p><p></p><h3>6.5
