## 五、怎么继续判一条内容

```bash
cd ~/.dsh/Momcozy知识库
kb/kbpy l5/matcher.py --text "<待判文本>" --json     # 确定性匹配；命中即 P0
kb/kbpy l5/matcher.py --file <文件> --json
```

**「否」也是结论**：写「未命中任何 P0 模式」，并注明这不等于内容合规（其余风险走 `kb-review`）。
