# kb-check 评测结论摘要（源 v1.1.0 · 2026-10-04）

> 完整报告：`kb-check-final-report.html`（单一 HTML，含 📊 测试报告 / 🧭 评测过程 / 🧪 测试用例 三大部分）

## 先纠一个前提

**「能不能上线」问错了 —— kb-check 已经是生产件，不是待放行候选。**

| 证据 | 内容 |
|---|---|
| `kb/l7/registry/skills.yaml` | kb-check 条目 `scope: 本项目` / `status: 生产` |
| `kb/l7/runs/*.json` | **292** 份 run 记录引用 kb-check |
| kb-repair 的 `depends_on_skills` | 含 `kb-check`（修复链以它为前置） |

正确的问法是「**放行判定过不过 / 该不该继续用**」。

## 结论：放行判定不过（market_ready = false）

| 轨道 | 结果 |
|---|---|
| 轨道 A（静态六维，内容质量参考） | **95.2** ｜ 2 error + 6 warning + 2 info |
| 轨道 B（触发盲测，A 卷 50 条 + 调用 3 条 × 3 轮 = 159 个全新子会话） | P **0.632** / R **1.000** / F1 **0.774**（口径 B：0.808） |
| 轨道 C（综合评分） | **63.7 → D 级（需大量返工）** ｜ market_ready = **false** |

### 三重阻断

1. **调用门槛未过** —— 3 条调用用例 9 次判定仅 3 次符合预期（`/kb-check` 三轮全「未加载」）。
2. **Output Quality 12/25 < 15** —— flaky 9 条 × 2 分触顶 −10；轨道 C 封顶 ≤79。
3. **Trigger F1 0.774 < 0.85 且 Trigger 分 13.7 < 15** —— 必须先改 description 再重测，综合评分最高 B。

## 但真实短板只有一类

- **正例侧极强**：16 条 × 3 轮 = **48/48 全触发，零漏触发**（R = 1.000）。
- **输出质量近乎满分档**：48 次回复全部产出契约要求的体检表（闸门 → 退出码 → 结论 → 证据），
  并落实「只报不改」、三种红口径、判据缺陷规避。
- **误报集中在边界 6 条**（18/18 次先开跑全库体检再声明边界）与「修 / 判据转述 / 破坏性动作」三类近似题。
- **调用门槛很可能是平台口径**：本机子会话不解析前导斜杠；「未加载」的会话照样按本 skill 的 §1/§3 作答。
  家族上一份报告（kb-canonical-lookup，2026-09-30）在同一台机器撞到同一堵墙。

## 优先修复（四处，按收益排序）

1. **§5 补「输入不完整 → 先追问」** —— 边界 6 条占误报的三分之二，改动成本最低。
2. **description 不适用清单补两类** —— 「把闸门脚本搬进 CI / 给我判据我自己实现」；「把红的那道顺手修掉」。
3. **正文补安全边界** —— 注入 / 索要凭据 / 越界路径三类，命中即拒绝（Release 第 8 项；高危目前为 0，属预防性加固）。
4. **补停用条件** —— Release 第 10 项。

## 本轮未做（明确披露）

- **未执行低分修复与 B 卷门禁**。理由：① 调用门槛是平台侧口径，改文本无法把 market_ready 翻成 true；
  ② 一次重测需再开 159 个真实子会话（本轮三轮实测约 136 分钟）。
- **B 卷封印未开封**（按流程仅副本交付前开卷）。
- 若需要，可在 `kb-check-fix/` 副本上落这四处修改并重跑全量 A 卷与 B 卷门禁。

## 评测侧发现（与 skill 无关，但值得单独处理）

1. **两个官方打分器口径不一致**：`score-trigger-eval.py` 把「不应触发」靠子串误判成 FN（边界 2 条），
   `build-final-report.py` 已修。本报告按修后规则回填（0.762 → **0.774**）。
2. **并发**：开跑时另一会话（f41c4909）正在评同一个 skill；同一工作台目录另有兄弟会话的预评/重评产物。
   基于提示词文本匹配的会话归集会串味（实测 58 条而应为 53 条），已改用 workflow childId 精确归集。
3. **活库副作用**：R3#7 落了体检表（§4 授权行为）；R2#18（负例误加载）删了一份他人备份目录；
   多条会话写 `kb/.work/.kb-loop-claim.json`（来自工作区 AGENTS.md）。
