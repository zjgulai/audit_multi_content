## 3. 为什么号补不齐 —— 四道闸，第一道是人裁

### 闸①　**6 个新形态在权威段表里没有段位**（人裁，技术绕不过）

权威分段表 `l4.json → numbering.block_by_library`（`scheme_version: article-no-2`）给 `external_standard` **只定义了 2 段**：

| 段 | 形态 | 状态 |
|---|---|---|
| `E-1` | `scoped_clause`（限定条款型） | 已发 375 |
| `E-2` | `clause`（法条型） | 预留·未发 |

而这 123 条的 6 个形态 `recommendation / substantiation / disclosure / prohibition / scope / mandate` —— **一个都不在段表里**，也不在**已废止**的旧表 `form_block` 里。取默认值 `block_of()=0` 会算出 **`E-0`**，而 **`E-0` 不在任何方案里**。

**这不是命名分歧，是两套词表撞了同一个字段名**：

| | 旧 375（`E-1`） | 新 123 |
|---|---|---|
| 记录键 | `clause_id` / `clause_text` / `unit_id` / `anchor` / `threshold` / `term_list` … | `rule_id` / `rule_text` / `condition` / `required_action` / `evidence_units` … |
| **键交集** | **仅 6 个** | |
| `form` 的**语义** | **记录结构**（scoped_clause = 限定条款型） | **义务动词**（`l3_clause_distill.py:238-252` 的 `rule_form()`：`must/shall`→mandate、`do not`→prohibition、`disclos`→disclosure…） |

新支线自己也知道会撞，代码里留了 `form_scope="external_standard"  # ★ 支线标识：与 wording 支线的 form 不混` —— 但**段表那边没同步**。

→ **可选项（人拍板，四选一）**：A 新开 `E-3…E-8` 六段 ｜ B 并入 `E-2`(clause) 从 `.1` 起 123 个 ｜ C 并回 `E-1` 从 **376** 起续（须同时把两套记录 schema 对齐）｜ D 把该字段改名（如 `obligation_kind`）让 `form` 回归结构含义，再按 B/C 落。
**这一条不裁，后面三步都算不出来。**
