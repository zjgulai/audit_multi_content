### 4.3 对装载真身的**文本级**判据（不依赖任何探针、可复现）

- 框架要求 [53]（裸 `/kb-check`）= **应加载 + 追问**。
- 装载真身 v1.2.0 的 description 逐字：`先追问、不要加载本 skill：… ② 只打 skill 名 …以上先问清别加载。`
- 裸 `/kb-check` **就是**"只打 skill 名"。

**⇒ 按它自己的说明做，就必然判"未过"。** 与探针跑几次无关。

**更强的一条**（来自 11:16 轮、被记为 **error 级**）：

> `[error] description :: 自相矛盾导致已声明触发词漏触发：知识库体检 同时出现在触发词清单与「先追问、不要加载本 skill：① 口令过短/只有名词/指代不明」口径里。实测（cwd=/tmp、加载 v1.2.0、单条全新会话）以该四字为题时模型选择先追问、不加载。`

⇒ **v1.1.0 的 [53] 是"少写一句"（可补）；v1.2.0 是"写反一句"+ 自相矛盾（须改写）。** 12:27 报告的判断方向我复核认可。

### 4.4 必须声明的一处证据质量偏差：**两套 F1 仪器，我采信能过硬校验的那套**

框架要求：新开 3 个被测会话、只发提示词原文、逐字回填。

## 10. 上线判定

> ## 不可以上线。`market_ready = false`。

**四条独立理由，任一成立即阻断：**

1. **调用门槛未过**（框架唯一硬门）—— **6 次测量、2 个版本、3 套仪器全判 false**，含最有利的 8/9。且对装载真身有**文本级**独立判据：description 既把 `知识库体检` 列为触发词、又写"先追问、不要加载本 skill：…只打 skill 名"，**自相矛盾**；实测该四字触发词**召不回自己**（error 级）。
2. **放行闸门自己判死** —— `--validate-only` 输出 `market_ready=false`，理由为 error 级 `track_b.call_tag`。
3. **轨道 C 不达线** —— 我的重算 75；三份独立实测 77／78.9／78.7；**全库无任何一份 kb-check 实测 ≥85**。

### 10.1 要过线，最小改动是**改写一处**（不是补一句）

```
先追问、不要加载本 skill：① … ② 只打 skill 名 ③ …
        ↑ ① 从「不要加载」清单移出「只打 skill 名」与已声明的触发词

```

**依据**：11:41 报告实测"两版三轮一致判未加载，是行为缺口不是模型抖动"；改后调用门槛可从 6/9 → 9/9，**解除唯一硬阻断**（该报告的原话）。
