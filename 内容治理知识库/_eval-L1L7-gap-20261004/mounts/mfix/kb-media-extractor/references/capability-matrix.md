# 能力矩阵：哪些模态真能抽、哪些只是契约

> 读这份文件的时机（见 SKILL.md §2）：**请求涉及视频 / 音频 / 关键帧 / 字幕，或用户问「这个到底能不能抽」时**。
> 纯图片 / 附件 / 链接抽取路径不必读。
> 本文件是**现状快照**，不是设计文档；每次引擎侧变化后由 L1 owner 更新，并在 `last_updated` 反映。

## 1. 逐模态对照

| 模态 | 对应引擎 | 现状 | 依据（可复算） |
|---|---|---|---|
| 图片（飞书「图片素材」字段） | `kb/l8/ocr_attachments.py` | **已实现** | 引擎按 record 下载附件 → macOS Vision OCR → 落 `kb/l1/media/media_<表>_<记录>/` + `_cache/<file_sha256>.json` |
| 附件字节（PDF / docx 等） | `kb/l8/store_l0_attachments.py`（只存档）、`kb/l8/apply_ocr_to_l1.py`（并入 L1） | **部分实现**：字节可归档；有文本层的可直接并入，**扫描件逐页 OCR 未进主引擎** | `store_l0_attachments.py` 产物只有字节 + sha256，不出正文 |
| 链接下钻（落地页正文） | `kb/l8/drill_links_2levels.py` | **已实现**（两层） | 写 `kb/l1/sources/**` |
| **视频字幕 / 口播转写** | `kb/l8/extract_video_asr.mjs`（2026-10-09 落地） | **已实现**：**macOS Speech.framework 本机 ASR**（on-device、零第三方、**不出机器**；`requiresOnDeviceRecognition=YES` 写死）→ 落 L1 `video_asr_segments`；`--apply` 时由 `extract_video_keyframes.py` **自动接** | 实测 2026-10-09：14 个视频 → **13 条有文本 / 4,236 字** ＋ 1 条 `no_speech`（**读数**：音轨里没人说话）。⚠️ **整段文本、无逐句时间码**（画面文字那半才有 `#t.`）；ASR 可能误识别 ⇒ **不得当逐字原文引用**；**画面文字 ≠ 口播内容**，两者**不得互相冒充** |
| **视频关键帧 OCR** | `kb/l8/extract_video_keyframes.py`（2026-10-08 落地） | **已实现**：ffmpeg 场景切换抽帧（不足按秒补、超上限等距抽稀）→ **走既有图片 OCR 通道**（同一台 macOS Vision、同一段 `ocr.jxa.js`、**同一套 `_cache/<图片sha256>.json`**）→ 落 `kb/l1/media/video_<slug>/frames/`，段锚点 `#t.MM:SS-MM:SS` | 实测 RUN 20261008-4000：11 个视频 → 253 帧 → **10916 字**可检索文本；重复文本按归一化去重但**合并时间窗** |
| 音频 / 播客 | — | **未实现**（现有 ASR **只接视频内嵌音轨**，不接独立的音频 / 播客文件） | 无对应引擎；家族内亦无成员承接。**别拿视频那条 ASR 冒充"音频也能抽"** |

## 2. 遇到「未实现」时的正确答复（不要编命令）

1. **说清是哪一支没实现**，并给出上面那条可复算的依据（引擎名 + 字段 + 现象）。
2. **不要**给出一条「看起来能跑」的命令，也不要拿画面 / 文件名 / 记录上下文凑一段正文（红线②）。
3. 给出可走的两条路：① 先按 L0 口径登记字节（`kb-l0-feishu`），等引擎落地；
   ② 需要文本才能做的事（审查 / 召回）必须先有文本，不能跳过。
4. 若确认是**契约与实现的偏差**，报给 `kb-check` / `kb-repair` 记一笔，不要在本 skill 里默默绕过。

## 3. 归属易混清单（与 SKILL.md §3 同步）

- 「附件字节只归档、OCR 不跑」→ `kb-l0-feishu`（不产文本时本 skill 无交付物）。
- 「图片上的字 → 判违规」→ `图片安全审查`（抽取只是取证动作）。
- 「把 OCR 正文翻译成中文」→ 家族内无成员承接；译文属派生产物，**不得写回 L1**（破坏逐字可核验性）。
- 「把抽取结果写进 ERP / 数据仓库」→ 不在本 skill 出口（出口是 L1），一律说明不适用。
- 「图片裁剪 / 去水印 / 压缩」→ 图像编辑，不是抽取，直接说明不适用。
