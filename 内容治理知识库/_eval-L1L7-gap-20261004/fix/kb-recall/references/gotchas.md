# Gotchas —— kb-recall（错误 → 修正）

> 由补充优化包加入（root-skills-creator 清单②③：gotchas 用「错误 + 修正」强模式，
> 并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：召回为空就说「库里没有」
  **修正**：先分三种：**索引未建 / 通道限制 / 真无命中**。三种证据不同，结论不能合并。

- **错误**：为了「查得准」去重建索引
  **修正**：查询档**只读**；重建 BM25 / 向量索引是写操作，归 `kb-pipeline`。

- **错误**：把 PDF / Excel 整文件读进上下文再检索
  **修正**：先读 `references/` 的处理方法（分层索引导航），再检索；整文件加载会撑爆上下文。

- **错误**：向量通道不可用时静默降级成单通道
  **修正**：**如实报降级**（受管解释器缺依赖等），不要把单通道结果说成双通道召回。

- **错误**：本 skill 不处理「这条为什么被判 BLOCK」的依据追溯，即使措辞看起来相似（「召回一下它的依据」）
  **修正**：依据与逐字摘录归 `kb-content-review`；召回只给**候选单元**。
