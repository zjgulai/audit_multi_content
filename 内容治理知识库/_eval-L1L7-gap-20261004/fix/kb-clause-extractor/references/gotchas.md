# Gotchas —— kb-clause-extractor（错误 → 修正）

> 由补充优化包加入（root-skills-creator 清单②③：gotchas 用「错误 + 修正」强模式，
> 并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：把素材抽单元当成抽条款
  **修正**：L1/L2 抽单元归 `kb-ingest-extractor`；本层只做**条款级**蒸馏。

- **错误**：把「蒸不出规则」当成失败
  **修正**：**拒绝台账是产物**：蒸不出的逐单元记拒绝理由，不是把整批判失败。

- **错误**：凭 LLM 归纳补一条规则候选
  **修正**：规则候选必须**锚在原文单元**（`unit_id` + `source_sha256` + `anchor`）上；锚不上的不许进候选。

- **错误**：只给一个名词（「蒸馏」）就开跑
  **修正**：**欠定先追问**要蒸哪份原文；没给原文不跑引擎。

- **错误**：本 skill 不处理发号与 canonical 定稿，即使措辞看起来相似（「把这条规则定下来」）
  **修正**：属**写操作**，归 `kb-pipeline`（L4）。查条款号则归 `kb-canonical-lookup`。
