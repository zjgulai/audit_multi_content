# Gotchas —— kb-check（错误 → 修正）

> 由补充优化包加入（root-skills-creator 清单②③：gotchas 用「错误 + 修正」强模式，
> 并写明「本 skill 不处理 X，即使措辞看起来相似」）。

- **错误**：把「闸门红了」直接说成「库坏了」
  **修正**：**区分三种红**：真坏 / **合法变化**（活库下冻结基线变红是正常的）/ **未判定**。混成一句会把正常状态报成故障。

- **错误**：体检完顺手把红项修掉
  **修正**：本 skill **只报不改**。要修走 `kb-repair`（它必须以一条已红闸门为输入）。

- **错误**：用 `envelope_census.py` 去扫 `.py` / `.txt`
  **修正**：它**只扫 `.md`**；`.py` / `.txt` 要另用 `tools/envelope_gate.py`。

- **错误**：`depends_on_engine` / `selftest` 里写 `~` 开头的路径
  **修正**：那两处**不做 `expanduser`**（`:1001–1002`、`:1018–1019`）⇒ 凡 `~` 开头都会被误报「不存在」。一律写**库根相对路径**。

- **错误**：用户只打本名就报「闸门全过」
  **修正**：**只打本名 / 只要判据不要跑** ⇒ 先追问**跑哪几道闸门**，不要假装跑过。

- **错误**：本 skill 不处理「闸门没过帮我修」，即使措辞看起来相似
  **修正**：归 `kb-repair`；本 skill 不写库、不删副本。

- **错误**：本 skill 不处理 L0→L7 供给链本身，即使措辞看起来相似（「把知识库同步到最新」）
  **修正**：归 `kb-pipeline`。
