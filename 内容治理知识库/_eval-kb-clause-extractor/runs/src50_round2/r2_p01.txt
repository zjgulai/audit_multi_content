## 二、`source_sha256` 怎么来（落库时的标准动作）

```bash
shasum -a 256 <原文文件>
```

⚠ **两个坑**：

1. **摘要要对着「源文件」算，不是对着剪贴板算**。你从网页/飞书复制出来的文本，和源文件字节不同（换行、全角半角、尾部空白都变），算出来的 sha256 对不上，回指链就是假的。
2. **`.md` 文件有个本机特有的坑**：这台机器上有些写通道（`python` 的 `open("w")`、`shutil.copy2`、`perl`、`sed >`）会在 `.md` 前面**落一层 4096 字节的信封**，而用 Python 自检**看不出**（stat/sha256/head 全报正常）。所以往装载位写 `.md` 一律走 **node 或 `/bin/cp`**，并且**用 node 读回逐字节校验**。本库 2026-09-29 就这么栽过一次，加载器报 `E001 × 509`，条目基线还被刷成 0 条。
