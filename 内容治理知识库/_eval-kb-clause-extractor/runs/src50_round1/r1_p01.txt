1. **有义务/禁止模态**（须 / 应 / 不得 / 禁止 / 有权 / required to / must / may not…）；
2. **落得了「命中 → 处理」形态**：要么有命中表达（词表），要么有阈值，要么有明确的处理动作。

**缺第 2 条的，无论多像规则，都不蒸**——因为蒸出来也没法判。

另外一关是**源侧资格**：源资源 `rule_eligible` 必须为 `true`；为 `false`（材料审核未通过）时**不得产出任何规则类形态**，只能出非规则形态或记拒绝。单元 `meta.content_quality_flag` 非空的也要先排除。

## 二、能蒸 / 不能蒸的对照（拿这张表去对语料即可）

| 语料形态 | 能不能蒸 | 原因码 / 处理 |
|---|---|---|
| 「不得使用 X 字等用语」 | ✅ 能（若 X 有词表） | 词表缺失则降级标 `needs_lexicon` |
| 「应在收到通知后 3 个工作日内整改」 | ✅ 能 | 硬阈值，可机械判定 |
| 「违反两次以上的，平台可下架」 | ✅ 能 | 次数阈值 + 处置动作 |
| 「禁止虚假宣传」这类纯概念禁令 | ❌ 不能 | 无命中表达、依赖外部事实 → 范围声明 |
| 「须符合某某法规要求」 | ❌ 不能（单独） | `obligation_without_action`：无处理方式、无阈值 |
| 「例如…」「The marketer…」情形描述 | ❌ 不能 | `policy_example_not_rule`：举例不是规范条款 |
| 陈述事实/背景/定义 | ❌ 不能 | `narrative_no_obligation` |
| 只有文案样本、源侧没给命中判定 | ❌ 不能 | `sample_only_no_verdict`（回源侧补列） |
| 引注残片（判例/条文引用） | ❌ 不能 | `citation_fragment_not_rule` |
| 描述主管机关权力/分工/执法史 | ❌ 不能 | `agency_authority_not_rule` |
| 单元是半句话 / 几千字连缀 | ❌ 不能 | `mid_sentence_fragment` / `oversized_unit_blob` → **回 L2 重切** |
| 一个单元塞了两个独立要求 | ❌ 不能 | `multi_requirement_merged` → **回 L2 重切** |
| 登记型字段值（元数据） | ❌ 不能 | `unit_level` |

## 三、回指要求（你点名要的）

**每条候选必须能回指原文，且是三件套同时给**：

- `unit_id`：L2 单元编号（20 位十六进制）；
- `anchor`：原文位置锚点（如 `#正文/para-12`，或表形态 `#数据表/recXXX/字段名`）；
- `source_sha256`：该单元所属源的指纹。

规则一行的 `evidence_units[]` 里逐条列这三样，`evidence_quote` 是**逐字摘录**（不转述、不概括）。只给「表@rev」这种粗粒度、给不出行级锚点的，回源时只能判断「这个表变过没有」，判断不了「哪条记录变了」——所以源侧的 `record_ids` 尽量一并给。

**没有回指的命中表达，不算合格候选**，哪怕它读起来很像规则。

## 二、切分口径（一条义务 = 一个单元）

切之前先按这个过一遍，你就知道你那句文本会切出几条：

1. **一句一义务**。但主语 / 条件 / 动作变了就必须断开——「商家未按时整改的，平台有权限制流量。限制后 7 日内仍未整改的，下架商品」这种，主体从商家变平台、条件从「收到通知」变「限制后满 7 日」，**必须切两条**。
2. **阈值不单独成条**。「两次以上」「3 个工作日」「7 日」是随条款走的字段，填进阈值/词表字段，不另起一条。
3. **序号不单独成条**。「B.」「第三章」这类标题会落 `heading_only`，正确处理是**标题与正文同单元**，不是切出个空条。
4. **一个单元最多一个独立要求**。塞了两个 → 落 `multi_requirement_merged`，判定为脏单元，**回 L2 重切**，不在 L3 硬容错。
5. **陈述句不是条款**。背景/定义/事实陈述（无「须/不得」模态）落 `narrative_no_obligation`，不进候选。
6. **举例不是条款**。「例如…」情形描述落 `policy_example_not_rule`，其规范结论在对应正文条款里。
7. **源侧要能给行级锚点**。只有「表@rev」这种粗粒度的话，回源时只能判断「这个表变过没有」，判断不了「哪条记录变了」——所以源带的 `record_ids` 请一并给我。
