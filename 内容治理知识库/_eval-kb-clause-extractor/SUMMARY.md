## 二、H1 的可证伪结论：**未被证实，方向相反**

v2 已按 H1 构造：description 撤出「不接」清单与安全边界（482 字符 ≈ 基线 474），
让位逻辑整体下沉正文 §5，精度只靠「正面收窄」（写明输入形态）。若 H1 成立，FP 应显著下降。
实测 **FP 由 8/4/7 升到 9/11/6，P 由 0.721 降到 0.653，F1 由 0.837 降到 0.789**。

可分离出的两条线索：
1. **让位清单确实属于正文** —— 撤出 description 后组合标签 FP 由 3 降到 2，这半句成立；
2. **误触发主因不在 description 的负面清单** —— 只加一句正面表述 FP 就反弹，被接管的仍是带「政策/规则/条款/台账」字样的近邻任务（77 NDA、81 目录清点、83 归档、87 目录树、97 PDF 汇报）。
   ⇒ 更可能来自 **catalog 层面的关键词共现与排序**，而非 description 措辞结构。

**另一条可复用观察**：v2 正例召回丝毫未动（16/16/16，R=1.000），说明所有改动只作用于精度侧 —— 「这是精度题」的判断成立，只是本轮没找到有效杠杆。
