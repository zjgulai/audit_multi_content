## 二、修复 ①：「有依据」= 能解析出登记来源（不再看"字段非空"）

- **根因（代码级）**：`tools/agent/model_side.mjs` 的
  `_hasBasis = !!String(raw.source).trim() || URL` —— **只看是不是非空字符串**；
  而提示词第 6 条恰恰教模型「实在找不到依据，就写 `source:"none"`」。
  ⇒ `basis_missing=false` ⇒ `dual_track.mjs:4051` 那道「缺依据不上卡」的过滤器放行 ⇒ 卡面印兜底句。
- **修法（三处，同一把尺）**：
  1. `_hasBasis` 改用 **`resolveSourceId()`**（闭集 S1–S17，与渲染侧 `ext_basis` 同一个函数）；

## 三、修复 ②：同一单跑完还能再跑，而且「第几次」说得清

**先说清楚一件事**：那条链**从来没有禁止过重跑**（换一个 `--base` 就是新 RUN）。
缺的是两样**读得出、核得到**的东西 —— 而没有判据的"没有禁止"，改一次代码就可能没有了。

- **新增 `kb/l8/rerun_ledger.py`**：只追加台账 `kb/.work/review_seq.ndjson`，每跑一单记一行
  （`base` / `text_sha8` / `state` / `content_id`）。判据是**纯函数**，可离线喂样本：
  - `check_base(rows, base, sha8)` → `same_base` / `rerun_of` / `rerun_seq` / `prev_state`；
  - **按素材指纹认，不按时间认**（补发单晚到 10 分钟也不能算错 —— 2026-10-08 栽过）；
  - 缺 `text_sha8` 的老行**不参与**比对（宁可少认一轮，也不把别人的上一轮贴到这一单上）。
- **`kb/l8/review_run.sh` 接了三处**：
  1. 开跑前判重跑；**同一个 BASE 硬拒 `exit 2`**（那是同一个 RUN 跑两遍：层记账被覆盖 + 台账双计，2026-10-03 实测过）；
  2. 旁挂新增 `rerun_seq / rerun_of / rerun_prev_state`（**成功路与拒答路都写**）；
  3. 两条路都记账（库忙 / 闸门红那几轮也算"跑过一次"）。
- **判据**：`kb/l8/workflow_smoke.py` 新增 **S12 重跑契约** ＋ 反向对照 **R12a / R12b**
  （把接线真拆掉 ⇒ 必须红；真文本 ⇒ 必须绿）。

**怎么重跑这一单**（源码级说明，不需要新工具）：

```bash
# 1) 换新 BASE 跑同一份素材（旧 RUN 的报告 / 层记账 / 表行一律不动，重跑只新增）
bash kb/l8/review_run.sh --base "$(date +%Y%m%d-%H%M)" --session "$DSH_SESSION_ID" \
  --decision-owner 图片安全审查 --loaded-skill 图片安全审查 \
  --material-file /tmp/<与上次同一份素材>.txt --content-type image

# 2) 想先看「这是第几次、上一轮是谁、上一轮结论」，不跑链：
python3 kb/l8/rerun_ledger.py --check-base "$(date +%Y%m%d-%H%M)" --text-sha8 <素材指纹>

# 3) 台账（只追加，不回洗）
tail -3 kb/.work/review_seq.ndjson
```

## 六之二、这次顺手发现、但**没动手**的两件（各自归属方收口）

1. **P0 快路打不中「最好」**（`Y8` 红）：`kb/l5/p0_patterns.jsonl` 17 条模式里没有一条把「最好」当 `match_term`
   ⇒ `p0_fastpath.py` 对「m5 pro是最好的吸奶器」`hit:false`。
   **推荐**：把「最好 / 最佳 / 最强」补进绝对化那条模式（属 L5 重建，要 `kb-pipeline` 写档 + 你点头）；
   **代价**：多打中一类素材 ⇒ 会多出 P0 BLOCK，回归集三态可能变（要重跑基线）。
2. **PRD §17 字数口径两边不一致**（`Z55` 红）：`prd17.countChars` 对「整行含 URL」的处理与测试期望不符
   （`5` vs `0`）。**推荐**：以 PRD 原文为准定一个口径，然后**测试与实现同一把尺**；
   **代价**：改动会让历史卡的 `prd17` 读数前后不可比 —— 要么只改测试（承认"整行不计"），
   要么改实现（链接行只扣 URL）。**我推荐先只改测试**：`linkLinesExcluded / linkCharsExcluded` 两个读数
   已经在证明"整行不计"，实现那条路是自洽的，而测试多要了一份不存在的口径。
