## 1. 通道证明 ✅（不是推理，是跑出来的）

用**现有 seed 规则**里的一条 P0 模式（`safe for baby`）造一条**标注清楚的夹具**，
走 `kb/l7/review-engine/core/offline_review.py`：

```
输入 observation：画面：婴儿床内放置了柔软枕头与毛毯，画面配文标注 'safe for baby'。
→ decision = REVIEW ｜ risk_items = 1
   risk_type : Health or safety outcome claim lacks approved substantiation
   risk_id   : US-CLAIM-HEALTH-001:26
   location  : **00:00:05 (observation[0]) text characters 26-38**
   extraction_source : {"kind": "observation", "index": 0, "location": "00:00:05"}
```

⇒ **`observations[]` 真的被当文本扫到了**，而且：
- **位置带时间码**（`00:00:05` —— 取自 observation 的 `timecode` 键，见 `media_adapter.py` 的 `value.get("location") or value.get("timecode")`）
- **带 `kind: observation` 标注** —— 下游能区分「这是**画面观察**」还是「素材自己的字」
- **带字符区间**（26-38）⇒ 可回指到那句话

这条证明的是：**只要有人把画面写成文本，它就能被判定、且能被定位、且能标出性质。**

## 2. ★ 规则缺口证明 ❌（同一通道，换个文本就露馅）

```
夹具 B：画面：行驶中的车辆后排，幼儿坐在成人腿上，**未使用安全座椅**；成人单手扶方向盘。
→ decision = **PASS** ｜ risk_items = **0**
```

**一条明明白白描述 PRD §7.3 一票否决项的观察，引擎判了 `PASS`。**

### 2.1 ★★ 这是 fail-open —— 所以**顺序不能反**

`_coverage_ready()` 对 video 要求 `text/video/audio/ocr/asr/keyframes`，本单这几格都是
`complete` / `not_applicable` ⇒ **不是覆盖缺口**，是**真"没命中"** ⇒ 落 `PASS`。

⇒ **若先把观察件接进去、规则后补，系统会把"没规则可判"显示成"判过了"。**
**这比"未测"更坏**（库规：「未命中 ≠ 合规」）。**⇒ 规则必须先立。**

### 4.2 ★ 观察件的**写法约定**（否则必然误报）

反向对照能过，靠的是一条约定：**观察件只写「画面里有什么」，不写「没有什么」**。
—— 因为「**无**安全座椅」（干净读数）与「**未使用**安全座椅」（违规）字面上极难区分，
而 `scan_text` 是**字面子串**匹配。**若允许写"无 X"，下面这句干净读数会被误判成红线**：

```
「无车辆、无安全座椅、无危险动作」 ←→ 模式「没有安全座椅」  ⇒ 一旦收宽就会命中
```

⇒ **约定必须写进观察件的产出规范**（谁产出 observation，谁遵守）。

## 5. ★ 另一个必须在动手前解决的问题：走这条路**只能产出「候选」**

命中的性质（实测）：

```
priority_tier = P0 ｜ action = **review** ｜ authoritative = **False**
```

`rule_engine` 自己写着：这一条是「**候选，不是依据**」（`superseded_by: kb/l3/candidates/rules.jsonl`），
理由文案逐字「命中美国市场规则候选，需要结合上下文、证据和适用范围人工确认」。

⇒ **PRD §7.3 要的是「命中即 BLOCK」**（无条款号的短语规则做不到）——
**候选只能到 REVIEW，达不到红线的语义**。

⇒ 画面类红线要成为**真红线**，得进**权威那条路**：
`kb/l5/p0_patterns.jsonl`（**11 条 P0 模式的正主**，带 `article_no` 条款号、带 `whitelist` 豁免机制），
而不是 `seed-rules.json`（那个文件自称 `authoritative: False`）。

**⇒ 这是 B1 查出的、比我原来估计更硬的一件事：B1 证明了通道，但"成为红线"还差一层（权威路 + 条款号）。**
